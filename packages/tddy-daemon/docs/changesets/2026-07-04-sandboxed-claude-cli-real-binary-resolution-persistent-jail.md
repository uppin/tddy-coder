# 2026-07-04 — Sandboxed claude-cli: real binary resolution + persistent jail `$HOME`

**Type:** Fix

`config::resolve_claude_binary_path` resolves the real host `claude` to an absolute path (prefers `~/.local/bin/claude`, skips Superset wrapper-shim dirs; `TDDY_CLAUDE_BINARY` / `claude_cli.binary_path` overrides) — a bare name emitted `(subpath "")` and made `sandbox-exec` reject the profile (exit 65 → `deadline_exceeded`). Adds a single daemon-wide **persistent jail `$HOME`** (`config::resolve_claude_home_dir`: `TDDY_SANDBOX_CLAUDE_HOME` > `claude_cli.claude_home_dir` > `$HOME/.tddy/sandbox-claude-home`), mounted read-write and seeded non-clobbering (`prepare_persistent_claude_home`, spawn passes `host_home: None`) so refreshed OAuth tokens/history/settings persist across sessions. `config::resolve_sandbox_config_path` resolves a per-OS `claude-sandbox.<os>.yaml` (loader is a follow-up).
