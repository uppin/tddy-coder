# 2026-07-27 — **cursor-cli-skip-keychain

**Type:** Fix

sandboxed cursor-cli sessions no longer hang on macOS Keychain** — `start_sandboxed_cursor_cli_session` now calls the new pure helper `sandbox_session::build_sandboxed_cursor_runner_env` (base runner env + `cursor_runner_env_overlay`) instead of inline env assembly; the overlay was previously defined in `tddy-sandbox-recipes` but never called from the cursor spawn path (only the Claude overlay was wired, unconditionally, via `build_sandbox_runner_env`), so even `CURSOR_TMPDIR` was never set in cursor sandbox sessions before this fix. The helper is pure (no `&self` deps), so the Keychain-skip behavior is unit-testable without a Seatbelt/cgroups harness. Specialized-subagent / LSP / semantic-index extensions remain inline in the spawn path (they depend on `&self` / runtime state). Tests: 1 fluent-style unit test in `sandbox_session::tests` (`cursor_runner_env_skips_keychain_so_the_jailed_agent_never_probes_securityd` — asserts `CURSOR_SKIP_KEYCHAIN=1`, `CI=true`, `CURSOR_TMPDIR`).
