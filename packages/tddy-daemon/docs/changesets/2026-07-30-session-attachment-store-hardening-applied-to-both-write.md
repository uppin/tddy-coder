# 2026-07-30 — session-attachment-store hardening applied to both write paths (merge of `master` into the start-materialization branch)

**Type:** Fix

the branch predated `master`'s store hardening and carried a `write_attachment_bytes` that re-introduced both defects it removed: an `if target.exists()` / `std::fs::write` pair (a TOCTOU window, and `fs::write` **truncates** an existing attachment instead of returning `FAILED_PRECONDITION`) and a discarded canonical dir (it wrote through the re-derived non-canonical path, so the containment check proved nothing about the path actually written). Both write entry points — `copy_attachment_into_session` and `write_attachment_bytes` — are rewritten on a shared `create_attachment_file_exclusively` helper (`OpenOptions::create_new(true)`: one atomic existence-check-plus-create; an existing regular file *or* a symlink planted in `artifacts/attachments/` is refused, never followed or truncated; a failed write removes the partial file), so neither path is the weaker gate. New `validate_attachment_basename` wraps the uploads path's `validate_segment` rule with a message naming the field the caller sent (`SessionAttachment.basename`) instead of `upload_id` / `file_name`; used by both store entry points and both `materialize_session_attachments` basename checks, while the staging RPCs keep the original message where those fields are real. Doc references repointed from the never-created `docs/ft/coder/amendments/session-attachments-start-materialization.md` to [session-attachments.md § Start-session materialization](../../../../docs/ft/coder/session-attachments.md#start-session-materialization) (5 sites), the RPC-table row for the staging RPCs corrected (it still said `UNIMPLEMENTED` with a dangling anchor) and a `ReadHostDocument` row added, and `connection_pb.ts` regenerated from the merged proto. Verified on the merged tree: build + `clippy --all-targets -D warnings` + `cargo fmt` clean, daemon/workflow suites green apart from one pre-existing `master` failure tracked in [docs/dev/TODO.md](../../../../docs/dev/TODO.md).
