# 2026-08-30 — a split agent reads its project's own guidance

**Type:** Feature

`build_split_context_dir` wrote a context directory holding nothing but the managed-codebase notice, and carried a `TODO(remote-managed-worktree)` saying so; a split agent saw the notice and none of the project's rules. It is now populated from the codebase daemon before the agent process spawns, on start **and** resume, and a failed fetch is a refusal that fails the session rather than a partial directory — the fallback decision the PRD deferred, resolved as no fallback. New `context_files.rs` serves it: a reader gated by the compiled-in allow-list rather than by git's listing, because that gate exists to keep `.gitignore`'d paths unreadable and agent config is routinely gitignored (`.claude/settings.local.json`, `**/.cursor/mcp.json`) — the two share every traversal and containment guard and deliberately share no gate. Three things make replacing it safe, and all three had to be built: no caller supplies globs; no caller chooses the row, since `context_agent_for_session` derives it from persisted state (a paired split session serves Claude's row — the codebase half is persisted as `workspace`, so `session_type` alone would have silently reduced every split session to `AGENTS.md`); and a resolved symlink's target must itself be allow-listed, or `.claude/creds -> ../.env` publishes a secret under an allow-listed name. That last rule was first applied to the manifest walk only, so the reader still served the link for a full validation cycle — the manifest omitting it is exactly what made it invisible. New `context_sync.rs` holds the manifest diff and one `synchronize_directory` that both setup and tick go through, after a resume that wrote without a delete pass left retracted skills permanently orphaned. ⚠️ **The re-sync trigger is not wired** — `ContextSyncer::tick` is tested but has no production caller, so "continuously synced" is the contract and not yet the behaviour; both blockers are recorded in [docs/dev/TODO.md](../../../../docs/dev/TODO.md). ⚠️ **Both halves of a split placement must be upgraded together**: start and resume now make two mandatory peer calls an older daemon cannot answer.
