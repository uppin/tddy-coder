# 2026-07-22 — **Worktree Code-pane file RPCs

**Type:** Feature

`ListWorktreeDirectory` / `ReadWorktreeFile`** — new **`worktree_files`** module browses a session's git worktree (`SessionEntry.repo_path`): `list_worktree_directory_entries` lists one directory level via `git ls-files --cached --others --exclude-standard -z` (dirs-first, `.git`-excluded, `.gitignore`-aware; a linked worktree's private `<gitdir>/info/exclude` is fed in via `--exclude-from`), and `read_worktree_file_utf8` reads a listed file with `..`/absolute rejection + canonicalize-and-contain and a 1 MiB cap (`truncated`/`byte_size`). Handlers reuse the `RemoveWorktree` preamble and gate on the new shared **`worktrees::worktree_path_is_listed`** (extracted from `remove_worktree_under_repo`); git/fs work runs in `spawn_blocking`. Tonic adapter delegates both. Units 8 (`worktree_files`) + integration 6 (`worktree_files_rpc`); `worktrees` regression 3/3, clippy clean.
