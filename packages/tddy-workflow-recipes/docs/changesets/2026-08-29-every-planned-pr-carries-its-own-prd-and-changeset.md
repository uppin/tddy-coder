# 2026-08-29 — every planned PR carries its own PRD and changeset

**Type:** Feature

a fourth goal, `write-stack-docs`, authors a document pair per node into `artifacts/prs/<node_id>/` between planning and the operator loop, kept out of the `write-stack-plan` submit so a plan refinement does not rewrite every document in the stack. `pr_stack::docs` holds the payload types, `node_doc_paths` (paths derive from `node_id` by convention — `StackNode` gains no field) and `validate_stack_docs`, which refuses a partial pass, an unknown node, a blank body, or a changeset missing any of `## Responsibility` / `## Boundaries` / `## Dependencies` / `## Draft PR contract`, writing nothing on refusal; headings match at line start tolerating trailing whitespace, so a mid-sentence mention does not satisfy one. `StackPlanned` now routes to the new goal and a new `StackDocsWritten` on to `orchestrate`; a seeded stack starts at the latter, since its node describes work that already exists. The goal is **registered** — proto, generated schema, `goals.json` — after #411 made a schema-less submit the odd sibling, and its prompt (beside its siblings in `plan_pr_stack::prompt`) emits JSON through the `--data-stdin` heredoc; a contract test lifts the prompt's own fenced example through the real CLI so prompt and schema cannot drift. Also corrects `stack-plan.yaml` and `pr-stack-plan.md`, written to the session root where no wire reader looks.
