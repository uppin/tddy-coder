# 2026-07-03 — PR-stack: free-prompting `orchestrate` loop + internal-status derivation + PR actions

**Type:** Feature

`PrStackRecipe::build_graph` drops the `begin-orchestrate`/`assess`/`spawn`/`merge`/`repoint` auto-loop for a single terminal `orchestrate` `BackendInvokeTask` (no successor edge → pauses for input); `next_goal_for_state[_with_changeset]` resumes into `orchestrate`; `orchestration_system_prompt` is chat-oriented; the `write-stack-plan` hook now seeds `Changeset.stack` (the removed `begin-orchestrate` was the only seeder). New `orchestrate_pr_stack::internal_status` (`derive_internal_status` from `NodeView`/`PrLiveStatus`/`effective_base_ref` + override-wins `reconcile_internal_status`) and `pr_actions` (`pr_merge_action`/`pr_close_action`/`pr_resolve_conflicts_action`, the last detect-only: probes a `--no-ff` merge, reports unmerged paths, always aborts, distinguishes a refused merge from clean). `GithubPrApi` gains `close_pr`. `OrchestratePrStackRecipe` documented as retained-but-inert (all CLI names resolve to `PrStackRecipe`).
