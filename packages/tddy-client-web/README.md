# tddy-client-web

Everything a tddy web component package may know about the outside world:

- **Generated RPC code** — `tddy-client-web/gen/<file>_pb` (protobuf messages and ConnectRPC service
  descriptors), generated by `bun run generate` and checked by `scripts/generated-code.sh check`.
- **The connection model** — `HostConnection`, `SessionConnection`, `ConnectionProvider`, the terminal
  feed types (`tddy-client-web/connections/*`). Providers (HTTP, Tauri IPC, LiveKit) are implementations
  the app registers; no component imports one.
- **Ports** — `ClientsProvider` / `useDaemonClient`, `useHostClient`, `useHttpClient`, `useSelectedDaemon`, …;
  `NavigationProvider` / `useAppLocation`; `AuthPortProvider` / `useAuth`.
- **Testkit** — `tddy-client-web/testkit`: port doubles and `withClients(jsx, backend)`; Cypress specs
  mount with `cy.mountWithClients(jsx, backend)`.

It imports nothing from `tddy-web` and nothing from LiveKit.
