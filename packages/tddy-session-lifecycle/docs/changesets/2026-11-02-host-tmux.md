# 2026-11-02 — The daemon's tmux host and the roster's tmux arm

**Type:** Feature

`HostTmux` (`connection_service/svc_terminal_ports/tmux_host.rs`) lists the user's tmux sessions as
that user and builds the attach argv; `CliManagerTerminalRoster`'s `Tmux` arm refuses a user the daemon
cannot become and a name tmux does not list, then starts the tab through `start_tmux_terminal`. Tests:
`tests/tmux_tabs_acceptance.rs` (7, on a private tmux socket) and 7 `tmux_host` units. Part of
[#806](https://github.com/uppin/tddy-coder/pull/806) — see [module-layout.md](../module-layout.md).
