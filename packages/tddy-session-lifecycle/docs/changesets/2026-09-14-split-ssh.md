# 2026-09-14 — Split workspace start carries ssh_config_host

**Type:** Feature

`ssh_client_daemon_instance_id` names the codebase host as the OpenSSH client when placement is
split. `workspace_start_request` continues to forward `ssh_config_host` on the workspace
`StartSession` via `..req.clone()`. Unit tests in `workspace_start_request_unit_tests.rs` and
`split_session::ssh_client_tests`.
