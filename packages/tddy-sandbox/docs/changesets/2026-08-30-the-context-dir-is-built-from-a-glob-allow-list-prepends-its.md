# 2026-08-30 — the context dir is built from a glob allow-list, prepends its notice, and is no longer 0444

**Type:** Feature

`CONTEXT_ROOT_FILES`/`CONTEXT_DIRS` are gone; `SandboxContextDir::create(source, globs)` copies what the session's backend actually reads, through `matches_context_globs` — the one predicate every consumer shares (this copier, the manifest walk, the daemon's reader, the syncer's deletes), because the recurring defect in this feature was two paths independently deciding what the directory may contain. `SANDBOX_REMOTE_APPENDIX` becomes `MANAGED_CODEBASE_PREAMBLE` and is **prepended**: the rule that the codebase is elsewhere is read before the project's own thousands of words, and a repo with no `CLAUDE.md` still gets one holding the notice. A symlink is followed only when it stays inside the source root **and** its resolved target is itself allow-listed — containment alone let `.claude/creds -> ../.env` publish a secret under an allow-listed name. New `context_manifest.rs` carries the matcher, a `BufReader`-streamed `sha256` (an over-cap file is left *out* of the manifest, never advertised for a read that would refuse it), and `diff_manifests`, which keys on the hash alone so an unchanged tick transfers nothing. `make_readonly_recursive` is deleted — a file mode cannot tell the host-side syncer, which must write, from the jailed agent, which must not; see the `tddy-sandbox-darwin` entry for what replaced it.
