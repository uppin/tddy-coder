# 2026-07-16 — Bash terminal tabs on the session participant

**Type:** Feature

new `session_participant/terminal_manager.rs` (`TerminalManager`, `PtyHandle`) spawns the user's passwd login shell in the session worktree via the new shared `tddy-pty` crate (rolling capture buffer for replay, broadcast fan-out, OSC-resize interception). `SessionConnectionServiceRpc::handle_rpc` now serves `StartTerminalSession`/`StopTerminalSession`/`ListTerminalSessions`/`SendTerminalInput` (unary) + `StreamTerminalOutput` (`RpcResult::ServerStream`, resize→replay→live broadcast), addressed by `terminal_id`; the reserved `main` stays the VirtualTui on `TerminalService` and `Stop("main")` is rejected with `INVALID_ARGUMENT`. `resolve_login_shell()` prefers passwd `pw_shell` over the (nix) `$SHELL`; `run.rs` wires a `TerminalManager` + worktree into both `SessionConnectionService` construction sites. Tests: 6 participant terminal-RPC tests (through the `handle_rpc` seam) + 4 shell-selection unit tests.
