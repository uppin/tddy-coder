# 2026-07-12 — Session-participant `ConnectionService` + `session` metadata + shared tool engine

**Type:** Feature

`src/session_participant/` (new) serves session-scoped `ConnectionService` (`ListExecTools`/`ListSessionToolCalls`/`ExecuteTool`/`ClaimTerminalControl`/`WatchTerminalControl`) from the coder's LiveKit participant; `DeleteSession`/`SignalSession` are intentionally NOT served (daemon-direct). `metadata_publisher.rs` maps `Changeset`+`SessionMetadata` → `session` JSON → `metadata_tx` (shallow-merged with `owned_project_count`/`codex_oauth`); `spawn_session_metadata_tap` subscribes to `PresenterEvent`s and publishes on transitions (interactive path; headless `--grpc` path FIXME-tracked `2026-07-12-fast-session-change`). `CoderSessionToolExecutor` dispatches `ExecuteTool` via the shared `tddy-tool-engine` against the session's `agent_working_dir` worktree root + a per-session `tddy_task::TaskRegistry`; `coder_session_tool_catalog()` mirrors the shared catalog; `ToolExecutor` seam is `async`. `run.rs` registers `ConnectionService` on the participant `ServiceEntry` (both `livekit_multi` + single-token paths) and wires `metadata_tx`. Tests: `coder_serves_connection_service_from_participant` + `coder_publishes_session_metadata_to_participant` (LiveKit testkit), 8 `metadata_publisher` tap-mapping unit tests, 2 `connection_service_participant` unit tests (catalog mirrors engine; `CoderSessionToolExecutor` Write→Read against tempdir).
