# 2026-03-08 — Agent Inbox

**Type:** Feature

Inbox queue in TUI for prompts during Running mode. Users type and press Enter to queue; items display between activity log and status bar. Up/Down navigate, E edit, D delete. Auto-dequeue on WorkflowComplete; workflow thread loops to accept new prompts. Queued prompts prefixed with instruction for agent. (tddy-coder)
