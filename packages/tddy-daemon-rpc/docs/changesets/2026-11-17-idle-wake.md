# 2026-11-17 — An idle orchestrator is woken by what it watches

**Type:** Feature · `#activity-wake` 3/5, PR [#931](https://github.com/uppin/tddy-coder/pull/931)

New `exec_tool/watch_wake.rs`: `WakeTrigger`, a bus subscriber that only notes which session to
look at and returns; the `WatchWaker` task behind `ExecToolRpcHandler::start_watch_waker`, which
settles a burst for 2 s, keeps 30 s between wakes, checks `orchestrator_is_idle`, and pastes
`wake_text` into the orchestrator's main terminal through `deliver_with`, committed only when
the paste succeeds. `paste_and_submit_to` is shared with `SendSessionMessage`'s paste path with
no behaviour change. Full record:
[`docs/dev/changesets/2026-11-17-idle-wake.md`](../../../../docs/dev/changesets/2026-11-17-idle-wake.md).
