# 2026-07-30 — **repointed-planned-pr-base-preselect

**Type:** Bug Fix

the Start-session "Base branch" picker pre-selects the planned PR's derived base and offers the project default branch, so a PR repointed onto `master` starts on `master`** — the option list (`prioritiseBaseBranchOptions`, stack branches only) and the pre-selection (`options[0]`) were computed independently of the dialog's `baseBranchLabel` (`deriveStackBaseBranch`), so they drifted: `RepointPlannedPr` drops every parent edge, and a node repointed onto the default branch showed the caption `origin/master` while the picker pre-selected — and submitted as `selected_integration_base_ref` — an unrelated stack branch, silently undoing the repoint; the default branch was not even an option. New pure resolver **`baseBranchChoice(node, nodes, defaultBranch) → { options: BaseBranchOption[], selected }`** (in `components/sessions/prstack/`) composes the two: `selected` is the derived stack base, the project default is appended last (unless a stack branch already names it), `selected` is therefore always one of `options`, an all-planned stack still yields `{ options: [], selected: "" }` so the picker stays hidden and the daemon resolves the base itself, and a legacy project with no `main_branch_ref` gets the empty ref under the label *"project default"* — hence `BaseBranchOption { value, label }` replacing the `string[]` on `CreateSessionInitialValues.baseBranchOptions`. `PrStackScreen` lifts each option's ref (and any label that *is* that ref) into `<remote>/<branch>` form. Tests: `baseBranchChoice.test.ts` 8 (bun), `PrStackRepointedBaseBranchPreselectAcceptance.cy.tsx` 3 (Cypress component, the live `attach-ui` repoint scenario); `PrStackStartSessionBaseBranchSelectAcceptance` option-list assertions extended with the trailing default and its inline `<option>` scraping replaced by a new `prStackScreenPage.dialogBaseBranchOptionValues()` helper; 643 bun + `vite build` clean. Feature folded into [pr-stacking.md § Operator-selectable base branch for a diamond node](../../../../docs/ft/coder/pr-stacking.md#operator-selectable-base-branch-for-a-diamond-node-added-2026-07-27).
