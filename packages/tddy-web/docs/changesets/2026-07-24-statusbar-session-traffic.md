# 2026-07-24 — **statusbar-session-traffic

**Type:** Feature

footer byte counter aggregates all attached sessions** — the screen-level `StatusBar` (→ `SessionTrafficStrip`) data plane changes from the focused session's room meter (`meterRegistry.get(attachment.livekitRoom)`) to a new `useAttachedSessionTraffic(runtimes, runtimeRegistry)` hook that sums every mounted runtime's per-session byte-tap counters (from [[inspector-byte-counter]]) for the totals and folds their positive advances into one shared `TrafficMeter` for the aggregate rate — so focused AND backgrounded runtimes contribute and the total is not reset by focus switches (a disconnected runtime is pruned). `runtimes`/`runtimeRegistry` thread `SessionsDrawerScreen` → `HostStatsFooter` → `StatusBar`; the shared meter-subscribe/interval logic is extracted to `useMeterSnapshot.ts` (reused by the HTTP meter). Tests: Cypress `SessionTrafficStrip` +3 (StatusBar aggregation), `SessionMainPaneTraffic` +3 (screen wiring + focused/backgrounded aggregate).
