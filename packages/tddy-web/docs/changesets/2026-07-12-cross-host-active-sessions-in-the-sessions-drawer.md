# 2026-07-12 — Cross-host active sessions in the sessions drawer

**Type:** Feature

the drawer shows any session with a live LiveKit participant regardless of the selected host. Liveness is participant presence in the common room (no `ListSessions` fan-out, no backend signal, no polling — the SDK's connection keep-alive keeps a live session's `daemon-<instance>-<sessionId>` participant present). The list is the union of the selected host's `ListSessions` (active + inactive) and the live cross-host participants, with owner + session id parsed from the participant identity; a live session the selected host didn't return is a minimal synthesized row. New `SessionManager` (`components/sessions/sessionManager.ts`) encapsulates the merged list + refresh + change events as one `useSyncExternalStore`-backed observable store, with a window-bound refresh bridge (`lib/sessionsRefreshBridge.ts`, mirroring `terminalZoomBridge`). Cross-host rows show an owning-host badge and route attach/resume/delete/terminate to the owning daemon (`useDaemonClientFor`); create + no-host-switch preserved. Unit `crossHostSessions` 10/10 + `sessionManager` 5/5; Cypress `SessionsDrawerCrossHostAcceptance` 8/8 (seeds common-room participants via `aFakeCommonRoom`); `SessionsDrawerAcceptance`/`SessionTerminateRefetch`/`SessionDrawer` regression green.
