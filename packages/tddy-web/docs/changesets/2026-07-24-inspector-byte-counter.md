# 2026-07-24 — **inspector-byte-counter

**Type:** Fix

Session Inspector I/O meter ticks live** — the Details tab's bytes in/out were stuck at `0` because `SessionRuntimeRegistry.recordBytes` was never called in production. `GhosttyTerminalLiveKit` gains an `onBytes` prop (held in `onBytesRef`) fired from the `streamTerminalIO` loop (`bytesIn = output.data.length` per received chunk, `bytesOut = data.length` per batched input yield); it threads through `SessionLiveKitTerminal` → `SessionRuntime` (`onSessionBytes`, incl. child runtimes) → `SessionMainPane` → `SessionsDrawerScreen`, which folds it into the runtime registry via new `makeByteTap(registry, sessionId, now?)` + `ByteDelta`. `recordBytes` now stamps `lastDataReceivedAt` only for inbound bytes (sending input no longer resets the "Ns ago" clock); the inspector renders counts via `formatBytes`. Distinct from the footer's transport-level `SessionTrafficStrip` meter. Tests: unit `sessionRuntimeRegistry.test.ts` 5 (makeByteTap in/out + inbound-only timestamp), Cypress `SessionInspectorByteCountAndLastReceived` 2.
