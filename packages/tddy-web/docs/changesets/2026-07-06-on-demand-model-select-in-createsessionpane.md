# 2026-07-06 — On-demand model select in `CreateSessionPane`

**Type:** Feature

a Model `<select>` for **tool** (tddy-coder) sessions as well as **claude-cli**, populated on agent change via a new `rpc/useAgentModels.ts` hook (`ListAgentModels({agent})`, loading/error/stale-response guarding). Switching agent re-fetches and resets the selection to the response `default_model`; the picked `model` is sent in the tool `startSession` (previously hardcoded `""`); the claude-cli dropdown is now fed from the daemon instead of a hardcoded list. A failed probe renders an inline error with the Model select empty and Create disabled — no fallback. `constants/claudeCliModels.ts` `CLAUDE_CLI_MODELS` is dropped from `CreateSessionPane` but **[~] retained** for the out-of-scope legacy `ConnectionScreen` (its `isClaudeCliSession`/CLI-session helpers unchanged). Test support: `cypress/support/rpc/responses.ts` `listAgentModels(...)` builder + `connectionServiceBackend.ts` seeding. Tests: Cypress `CreateSessionModelSelectionAcceptance` 7/7, `CreateSessionPane` 29/29. Feature [tool-session-model-selection.md](../../../../docs/ft/web/tool-session-model-selection.md).
