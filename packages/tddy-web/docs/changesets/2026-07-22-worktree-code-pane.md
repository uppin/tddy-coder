# 2026-07-22 — **Worktree Code pane

**Type:** Feature

split-screen file tree + preview for every session type** — a **Code** toggle in `SessionMainPane` (beside Inspector, shown for every session type) opens a horizontal `react-resizable-panels` split (`^3.0.6`, classic `PanelGroup`/`PanelResizeHandle` API): the base view (terminal/chat/PR-Stack) stays in a stable always-mounted `Panel` (so toggling never re-mounts a live terminal or chat), and a `WorktreeCodePane` opens beside it. Load/read failures surface instead of hanging. New testids `sessions-code-toggle`/`worktree-code-pane`/`worktree-file-tree`/`worktree-file-preview`/`worktree-tree-node-<relPath>`; `worktreeCodePanePage` page object.
