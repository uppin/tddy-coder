# 2026-07-23 — Inspector docks as the main pane for disconnected sessions

**Type:** Feature

the Session Inspector renders as the full main pane (not a ~360px overlay drawer) when the selected session is `disconnected`, driven by a new `data-docked` attribute on `sessions-inspector-drawer` derived from a pure `isInspectorDocked(session)` helper (`inspectorState.ts`; docked iff `connectionStatusForSession === "disconnected"`, so `connected`/`needs-input` stay drawers). `SessionInspectorDrawer` gains a `docked?` prop that switches the open/expanded footprint to `left-0 right-0 w-full` while keeping all header controls; `SessionMainPane` computes `docked = isInspectorDocked(selectedSession)`, passes it down, and suppresses the focused runtime while docked (`focused={!docked && r.sessionId === focusedRuntimeId}`) — so a disconnected session renders no `sessions-detail-terminal-container` and no "Claim terminal" overlay, while the runtime layer stays mounted (background streaming preserved). Tests: unit `inspectorState.test.ts` `isInspectorDocked` (5), Cypress `SessionInspectorDockedDisconnected` 5/5 (regression: `SessionInspectorAcceptance` 13, `TerminalControlAcceptance` 4, `SessionMainPaneTraffic` 4, `SessionMainPaneUnscopedSession` 1).
