# 2026-07-19 — Child conversations rendered as session tabs

**Type:** Feature

new `components/sessions/useChildSessions.ts` derives `childSessions = sessions.filter(s => s.orchestratorSessionId === parentSessionId)` from the drawer session list (no new RPC — rides the existing `SessionEntry.orchestrator_session_id`). `SessionTerminalTabs.tsx` accepts `childSessions` + `onSelectChild` and renders a tab per child (testid `sessions-child-tab-<sessionId>`) after the bash tabs, before `+`. `SessionRuntime.tsx` extends the active-tab state to a discriminated union (`agent`/`bash`/`child`) and attaches + mounts the selected child session's runtime pane; `SessionMainPane.tsx`/`SessionsDrawerScreen.tsx` pass the enriched session list down. Test support: `sessionTerminalTabsPage` `childTab`/`childPane`, `testIds.sessionsChildTab`, `aSessionEntry` `orchestratorSessionId` override. Tests: Cypress `SessionChildTabsAcceptance` 3/3 (`SessionTerminalTabsAcceptance` 5/5, no regression).
