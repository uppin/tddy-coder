# 2026-07-24 — **sessions-drawer-active-separator

**Type:** Feature

Active/Remaining collapsible partitions in the session drawer** — the open `SessionDrawer` splits its list into an **Active** partition (green/yellow dots: `connectionStatusForSession(s) !== "disconnected"`, i.e. `isActive || pendingElicitation`) and a **Remaining** partition (grey/disconnected), separated by collapsible `Active (N)` / `Remaining (M)` headers. New `SessionDrawerSeparator` is a `<button>` disclosure (body hidden via `display:none`) — deliberately not a nested `<details>`, so stack-group `<details>` counts stay intact. New `partitionSessionsByActivity()` filters by dot first, then runs `groupSessionsByStack` on each side independently, so a mixed-activity PR-stack splits by each session's own dot; the separators render only when both partitions are non-empty (else a single flat list, unchanged). Active expanded / Remaining collapsed by default; selection mode passes `forceOpen` to both so bulk delete still spans them. Extracted `SessionPartitionBody` (dedupes the groups+flat render); added `sessionsDrawerPage.expandRemaining()` and adapted two mixed-fixture specs (`SessionInspectorAcceptance`, `SessionStartResumeStillDaemonRouted`) to expand Remaining before clicking a now-collapsed disconnected row. Tests: unit `sessionStackGroups.test.ts` +8 (14 total), Cypress `SessionsDrawerActiveSeparator` 8.
