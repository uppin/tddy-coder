# 2026-07-23 — **unify-web-layout

**Type:** Feature

shared AppShell, sessions drawer as the default route, dedicated LiveKit screen, unified theme** — all daemon-mode screens now render inside one `AppShell` (`src/components/shell/AppShell.tsx`, `scroll` + `fullbleed` variants) owning the top chrome (top-left hamburger `DaemonNavMenu` + title + `DaemonSelectorConnected` + `UserAvatar`, sourced from `useAuthContext`), so no screen can ship without the nav menu; `SessionsDrawerScreen`, `TasksDrawerScreen`, `ProjectsAppPage`, `VmsAppPage`, `WorktreesAppPage`, and `RpcPlaygroundAppPage` were migrated onto it. The **sessions drawer is now the default route** — `index.tsx`'s routed switch renders `<SessionsDrawerScreen>` as the catch-all (`#/`, `#/sessions`, `#/sessions/:id`) and the legacy monolithic `ConnectionScreen` + its `#/terminal/:id` route are removed, along with `ConnectionScreen`-only helpers `connection/agentOptions` and `connection/multiSessionState` (kept `terminalPresentation`); `appRoutes.ts` adds `LIVEKIT_ROUTE`/`isLiveKitPath` and drops `isSessionListPath`/`terminalPathForSessionId`/`terminalDeepLinkSessionPath` (keeps `parseTerminalSessionIdFromPathname` for the standalone hash-strip). `DaemonNavMenu` collapses the old "Sessions"(`/`) + "Sessions (new)"(`/sessions`) into one **Sessions** entry and adds a **LiveKit** entry. New **`LiveKitAppPage`** (`#/livekit`) renders the "Connected participants" panel extracted from `ConnectionScreen` (`ParticipantList` fed by `useRoomParticipants(room)` + `useObservedCommonRoomStatus(room)` off `useSelectedDaemon().room`). Ported into the drawer: bulk row-select + delete (`session-row-select-<id>` checkboxes in `SessionDrawerItem` → `sessions-drawer-bulk-delete`, deletes in selection order) and an unknown-session not-found state (`terminal-route-unknown-session[-home]`) shown in the **detail pane only** (drawer stays visible) when a `#/sessions/:id` deep link matches no loaded session. Standalone `ConnectionForm`/`DaemonLoginScreen` re-themed from inline hex to shadcn tokens. Tests: unit `appRoutes.test.ts` (`isLiveKitPath`; 31/0); Cypress `AppShell` 3, `UnifiedLayoutAcceptance` 3, `LiveKitScreenAcceptance` 1, `SessionsDrawerBulkDeleteAcceptance` 1, `SessionsDrawerUnknownDeepLinkAcceptance` 1, `StandaloneFormThemeAcceptance` 1, regression `SessionsDrawerAcceptance` 23/23; e2e `app-routing-daemon` (real GitHub-stub auth: `#/` → drawer + hamburger) plus a harness fix adding `livekit.api_secret` to `startDaemonWithDemoTui`'s generated daemon.yaml (session-token signing). Removed obsolete `ConnectionScreen.cy.tsx` / `ConnectionScreenSharedCommonRoomAcceptance.cy.tsx` / `sharedCommonRoomPage.tsx` and the `/terminal`-era `AppRouting.cy.tsx` / `app-routing-deep-link.cy.ts`.
