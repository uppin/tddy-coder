# 2026-08-14 — "Codebase host" in `CreateSessionPane`, and a codebase-host badge in the sessions drawer

**Type:** Feature

a second `<select>` inside the claude-cli managed-codebase block places the session's worktree on another daemon (`codebaseDaemonInstanceId`), defaulting to "Same as host". Two predicates keep the form honest about what a split cannot also ask for: `canChooseCodebaseHost` (claude-cli, managed, not peer mode, a common room to name a host in) gates the control, and `isSplitCodebase` builds on it to withdraw the recipe, sandbox, semantic index and `--dangerously-skip-permissions` — each of which the daemon refuses by name, so leaving them on offer meant the *only* thing the selector could produce was a rejected request. Naming the session's own host is treated as co-located, matching the daemon, rather than as a split that silently drops the workflow recipe. `SessionDrawer.badgeCodebaseHostLabel` badges a split row's codebase host through the same label mapping as the agent host, and only for rows that have one.
