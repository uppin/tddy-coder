# 2026-08-14 — LiveKit rooms & participants panel

**Type:** Feature

a second panel on `#/livekit` lists every room on the LiveKit server with the participants joined to each, fed by `ConnectionService.StreamLiveKitRooms` (snapshot first, then one change event per delta) through `useLiveKitRooms` + the pure `liveKitRoomsState` fold; the existing Connected participants panel is untouched, so the common room shows in both from independent sources (client SDK vs. server API). Participant metadata moved from a column to a Radix card on hover **and keyboard focus** — reachable without a pointer, which is also what made it testable, since the component harness cannot synthesize the pointer events Radix listens for. `safeTestIdPart` was extracted to `src/lib/testId.ts` because three copies with identical regex meant a component and its selectors could drift and every dynamic `data-testid` would silently miss instead of failing. Fixed on review: the hook never aborted on unmount (a `cancelled` flag is only read when the next event arrives, and this feed is silent when idle), and one acceptance test passed vacuously against the pre-change DOM.
