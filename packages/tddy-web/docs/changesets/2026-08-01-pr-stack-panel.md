# 2026-08-01 — **PR-stack panel

**Type:** Feature

expandable rows, session links, persisted order, base-sync badges, pull-from-base** — `PlannedPrRow` split into a toggle header, an always-mounted `display:none` detail body (`PlannedPrRowDetails`) and an always-visible error footer, with `PlannedPrRowBadges` returning a **fragment** so badges stay siblings of the toggle (a button inside a button would swallow the Start-session click); hiding rather than unmounting keeps expansion, scroll position and the poll set across a collapse *and* keeps eight existing specs green untouched. The status chip is **wrapped**, not replaced, in `pr-stack-session-<nodeId>`, which selects and attaches the bound child session via a `onOpenSession` threaded through `WorkflowViewContext` (reusing `SessionMainPane`'s existing peer switcher). New pure modules `orderStackNodes` (persisted order when every node carries one, else `topoSortStackNodes` **wholesale** — a half-numbered plan can otherwise render a child above its parent), `parentTitles`, `boundChildSession` (plan first, branch owner second, both guarded on the session being known so a control never selects nothing), `branchQueries` (pairs each branch with its base, which also fixes a root node's base never being polled at all), `baseSyncStatus` (`unavailable` outranks the counts; `in-sync` is a badge rather than silence, or a healthy row and an unanswered poll would look identical). `useQueryBranch` keyed by branch+base with monotonic write tickets, so a poll issued before a pull cannot clobber its result, and a branch's cached comparison is dropped when its base changes. One per-node in-flight guard covers merge, rebase **and** repoint — repoint rebases and force-pushes the branch a pull merges into, and the state where both render is the normal post-merge state. A pull that landed locally but failed to push says so rather than reading as an unqualified success. `DirtyWorktreeDialog` prompts before touching a worktree with uncommitted work. Tests: 7 new Cypress specs, 6 new bun unit modules; suite at 774 Cypress / 702 unit. (tddy-web)
