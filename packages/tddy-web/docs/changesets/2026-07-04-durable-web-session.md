# 2026-07-04 — **Durable web session

**Type:** Feature

single-flight token store + RPC auth gate** — new `sessionTokenStore.ts` (dual-token `localStorage`, client-side `exp`-decode, single-flight `ensureFreshAccessToken()`) and `authGateInterceptor.ts` (ConnectRPC interceptor wired into the HTTP transport that awaits a fresh token and rewrites each request's `sessionToken` field at send-time) replace sole reliance on `AuthProvider`'s 4-minute `setInterval`; a refresh is now triggered transparently on mount whenever the stored access token has expired but the refresh token is still valid, so waking a slept device/backgrounded tab no longer drops the user to the login screen. `AuthProvider` exposes `isRefreshing`; `UserAvatar` shows a top-bar "Refreshing…" indicator while a refresh is in flight. TS units 8/8; new `DurableSessionAcceptance` Cypress spec 5/5; `AuthProviderRefreshAcceptance` rewritten for the two-token contract, 4/4.
