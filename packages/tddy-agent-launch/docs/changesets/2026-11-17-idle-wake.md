# 2026-11-17 — An idle orchestrator is woken by what it watches

**Type:** Feature · `#activity-wake` 3/5, PR [#931](https://github.com/uppin/tddy-coder/pull/931)

`IdleObservation` gains `holds_live_watch`, and `should_stop` never stops a session holding a
live session watch: a project-home main waiting to be woken stays up, and the ordinary idle
clock applies again once its last watch ends. `LaunchSessions.session_watches` carries the watch
store and notification log to the reaper. Full record:
[`docs/dev/changesets/2026-11-17-idle-wake.md`](../../../../docs/dev/changesets/2026-11-17-idle-wake.md).
