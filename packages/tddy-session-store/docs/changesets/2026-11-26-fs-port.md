# 2026-11-26 — Session-store reads and writes through the filesystem port

**Type:** Architecture · PR [#1045](https://github.com/uppin/tddy-coder/pull/1045)
Cross-package entry: [`docs/dev/changesets/2026-11-26-fs-port-crate.md`](../../../../docs/dev/changesets/2026-11-26-fs-port-crate.md)

`atomic_file` is a re-export of `tddy_fs` (same three functions at the same path; the
implementation and its tests moved to the port). Session files, the `.impl-session` file,
session-directory creation, cross-reference injection, manifest parsing, action discovery and
allowlisted-path resolution each keep their signature and delegate to an `_on` form taking
`&dyn tddy_fs::Fs`, with `DiskFs` as the production adapter. Discovery walks the port instead of
`glob` (a root holding glob metacharacters is now walked literally); the `glob` dependency is
gone. Manifests without `summary`/`architecture` parse with empty defaults, so discovery still
lists a manifest that names only its `id`, `version` and `command`. `tests/fs_port.rs` pins the
MemFs behaviour and runs the port guard over `src/`. Detail:
[architecture.md](../architecture.md).
