# 2026-07-03 — `--claude-arg` pass-through + plain-HTTP forward proxy + persisted MCP logs

**Type:** Feature

new repeated `--claude-arg` (`allow_hyphen_values`) appended verbatim to the in-jail `claude` argv after the fixed flags + before the MCP args (the MCP block's trailing `--mcp-config` is variadic and would otherwise swallow a trailing positional prompt); ignored in `--pty-command` mode. Egress shim gained a forward-proxy path: `rewrite_http_proxy_request` (absolute-form → origin-form, extracts host:port) + `handle_http_forward` (relay tunnel; host owns the outbound socket — no jail net rule needed); CONNECT handler refactored to share `open_relay_tunnel` + `pump_tunnel`, so `base_url: http://localhost:11434` works as-is. `write_claude_mcp_config` now writes a `tddy-tools --mcp` `env` block; the runner sets `TDDY_TOOLS_LOG_FILE` → `<session-dir>/egress/tddy-tools.mcp.log` and `RUST_LOG` (default `info,tddy_tools=debug,tddy_discovery=debug`, override via `mcp_log_level` config / `--mcp-log-level`); app maintains a `<session-base>/sessions/latest` symlink.
