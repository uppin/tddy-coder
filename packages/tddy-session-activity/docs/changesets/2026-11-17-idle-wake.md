# 2026-11-17 — An idle orchestrator is woken by what it watches

**Type:** Feature · `#activity-wake` 3/5, PR [#931](https://github.com/uppin/tddy-coder/pull/931)

`SessionWatchStore::deliver_with` hands an owner's waiting delivery to a closure and commits it
— positions advanced, ended watches removed, persisted — only when the closure succeeds; a
refused delivery moves nothing, so a wake whose paste failed delivers nothing. Full record:
[`docs/dev/changesets/2026-11-17-idle-wake.md`](../../../../docs/dev/changesets/2026-11-17-idle-wake.md).
