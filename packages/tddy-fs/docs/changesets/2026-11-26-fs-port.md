# 2026-11-26 — One filesystem port (tddy-fs), with session-store and credentials on it

**Type:** Architecture · PR [#1045](https://github.com/uppin/tddy-coder/pull/1045)
Cross-package entry: [`docs/dev/changesets/2026-11-26-fs-port-crate.md`](../../../../docs/dev/changesets/2026-11-26-fs-port-crate.md)

New leaf crate `tddy-fs` (std + `uuid`, `tokio` optional): the `Fs` trait, `DiskFs`, `MemFs`
(in-memory tree with modes, atomic-write semantics and write-fault injection), and the `AsyncFs`
facade behind the `tokio` feature. The crash-safe atomic write is a port operation
(`write_atomic` / `write_atomic_with_mode` / `write_atomic_labelled`); both adapters pass one
shared conformance suite, and `testing::direct_disk_io_in` is the guard migrated crates run over
their own `src/`. Resolves `docs/dev/todo/2026-09-23-atomic-file-leaf-crate.md`
("Two copies of \"replace a secret without truncating it\""): this crate is the leaf crate it
asks for. Detail: [filesystem-port.md](../filesystem-port.md).
