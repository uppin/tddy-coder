- **2026-08-15** [Feature] **session-worktree-sync** (partial) — new crate: the client that mirrors a session's worktree by watching its LiveKit room. `credentials` resolves flags with per-parameter environment fallback over the repo-root `.env`, as a pure function on an injected map so every rule is testable without `set_var`; an already-set variable always wins, an unparsable `--connect-timeout-secs` is refused rather than silently becoming 30 s, and `LIVEKIT_API_SECRET` has **no flag** because an argv is world-readable through `/proc`. `mirror` owns its destination outright — a `.tddy-session-sync.json` marker, a refusal to adopt a non-empty unmarked directory or one marked for another session, de-duplication by tick `seq` so the several calls sharing a poll window apply one patch once, and `git apply --check` before any write so a rejected patch cannot leave a half-applied mirror. `apply` names the three ways a mirror diverges and carries what it saw, because those strings are what an operator reads. **The room attach and the sync loop are not built**, so the binary resolves its settings and exits non-zero; the daemon-side RPCs it will call answer `unimplemented`.
