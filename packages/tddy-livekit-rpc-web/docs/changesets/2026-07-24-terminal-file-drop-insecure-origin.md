# 2026-07-24 — **terminal-file-drop-insecure-origin

**Type:** Fix

`LiveKitTransport.unary` honours `timeoutMs`** — the third `Transport.unary` parameter was accepted as `_timeoutMs` and **ignored**, so no request on the LiveKit path had a deadline; a chunk-framed request whose frames are dropped in transit leaves the peer's `ChunkReassembler` permanently incomplete, so the call hung forever with no error (a real browser file-upload failure). A deadline timer now drops the pending entry and rejects with `ConnectError(Code.DeadlineExceeded)`, cleared on response/error/abort; callers passing no timeout keep the previous indefinite behaviour (deliberately opt-in — `StartSession` does slow remote git work). `MAX_CHUNK_FRAME_BYTES` is now exported from `index.ts` so payload producers can size requests to one packet and pin it in a test. Known remaining gap: `publishRequest` still fires each frame at `publishData` without awaiting, so oversized messages burst with no SCTP backpressure. Tests: `transport.test.ts` +3 (deadline fires, prompt response unaffected, no-timeout callers never time out).
