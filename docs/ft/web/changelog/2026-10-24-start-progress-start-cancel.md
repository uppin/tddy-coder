# 2026-10-24 — Cancel a session start from the create pane

While a session is being created, **Cancel** cancels the start instead of being disabled. It reads
**Cancelling…** until the host has stopped and cleaned up, then the form is editable again with its
values, and **Start cancelled** is shown. This works in the sessions drawer and in the PR-Stack
**Start session** dialog. See [Session drawer § Cancel](../session-drawer.md#cancel).
