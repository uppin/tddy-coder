# 2026-11-15 — Rename, delete and restore a project from the web

The drawer's project settings pane renames a project and deletes it, behind a confirmation saying its
data is kept. The Projects screen's **Show deleted projects** lists deleted projects with **Restore**.
The drawer hides a deleted project and its sessions. See
[Projects screen § Deleted projects](../projects-screen-multi-host.md#deleted-projects) and
[Session drawer § Project settings pane](../session-drawer.md#project-settings-pane).
