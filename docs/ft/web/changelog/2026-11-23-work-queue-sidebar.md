# 2026-11-23 — The work queue is a sidebar

The work queue moves from an inspector tab to a right sidebar sharing Agent Activity's slot (mutually
exclusive; a queue owner opens on it). Tasks stack vertically with right-gutter brackets for PR-stack
line edges and a drag handle each — disabled for tasks bound to a PR stack, a persisted `ReorderWorkItem`
move for free ones. See [Session drawer § Work queue sidebar](../session-drawer.md#work-queue-sidebar).
