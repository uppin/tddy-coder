# 2026-10-20 — Full-screen remote desktop viewer

The desktop viewer, on both scopes, can take the whole screen. Where the browser supports Keyboard Lock, Esc, Alt+Tab and similar keys then reach the desktop; where it does not, the viewer says Esc leaves full screen. Closing the desktop leaves full screen. See [Screen sharing sessions](../screen-sharing-sessions.md) (AC-SS-6).
