# 2026-11-14 — Start an orchestrator from the project entry

Each project header in the session drawer has a "+". It opens a composer with a prompt box
centred in the detail pane and model, effort, provider account, host and attachment controls
under it. Sending starts an orchestrator session for that project with the text as its first
prompt and selects it. Every listed project shows a header, so the "+" is reachable even for a
project with no sessions yet.

See [Session drawer § Orchestrator composer](../session-drawer.md#orchestrator-composer).
