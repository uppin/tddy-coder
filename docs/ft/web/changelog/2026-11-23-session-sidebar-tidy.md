# 2026-11-23 — Tidier sessions drawer

Projects with active sessions are pinned to the top of the drawer; project headers drop the session
count; the settings gear moves left of the project name and shows on hovering the header row. PR
stacks leave the project groups for one **Stacks** box above Select, which opens upward with stacks
grouped per project and named by title or owning session instead of a raw id. Active sessions
are listed with no header and the rest fold under a right-aligned **More (N)**;
project names line up with the session dots, the gear taking the chevron's place on hover;
project-home sessions and the pinned main carry a house icon. See
[Session drawer § Stacks box](../session-drawer.md#stacks-box).
