# 2026-10-15 — Local gh toggle on the Projects screen

- **A Local gh checkbox on each project card.** Turning it on removes the project's GitHub account
  assignment and keeps other providers'; turning it off leaves no GitHub account assigned.
- **The GitHub account picker is hidden while it is on.**
- **Each host row shows its own `gh` state** for the project's GitHub host: logged in as a login, not
  logged in, not installed, or could not be read with the reason. A git URL that names no GitHub host
  is said so.
- **Account assignment is described accurately:** it is written to the host the request names, not to
  every host owning the project.

See [Projects screen & multi-host projects § Local gh](../projects-screen-multi-host.md#local-gh).
