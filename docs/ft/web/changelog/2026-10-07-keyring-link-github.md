# 2026-10-07 — Add account on the Accounts screen

`#keyring` 8/9 — PR [#515](https://github.com/uppin/tddy-coder/pull/515).

Each provider group on the **Accounts** screen offers **Add account**. It shows the code to type and
where to type it, checks after the interval the daemon names, and ends as linked, refused, expired or
vault locked — each said as itself. The account your session was established with is marked and has
no remove control. See [Accounts screen](../accounts-screen.md).
