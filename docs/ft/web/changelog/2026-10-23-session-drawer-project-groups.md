# 2026-10-23 — Session drawer groups sessions per project

The expanded session drawer shows one collapsible group per project, headed by the project's name and session count and ordered by name, with a trailing **Other** group for sessions that have no known project. The Active / Remaining split and stack nesting apply inside each group. Collapsed groups are remembered per viewer, and selecting a session expands its group.

See [Session Drawer](../session-drawer.md#project-groups).
