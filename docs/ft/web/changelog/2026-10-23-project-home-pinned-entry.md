# 2026-10-23 — A pinned main entry in each project group

Each project group in the session drawer starts with a pinned **main** entry: one click starts,
resumes or reaches the project's read-only home session and selects it. A project with no home
agent shows a hint instead; a project with a home agent and no session yet still gets its group. See
[session drawer § Pinned main entry](../session-drawer.md#pinned-main-entry).
