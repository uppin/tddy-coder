# 2026-11-03 — "Run the agent in tmux" on the Create pane

The Create pane offers **Run the agent in tmux** for a Claude CLI session. It is disabled, and cleared, while the sandbox, the sandboxed codebase or a split placement is chosen, and it is not offered on the project's main session. See [Session drawer](../session-drawer.md). Part of [#814](https://github.com/uppin/tddy-coder/pull/814) (`#tmux-agent` 1/3).
