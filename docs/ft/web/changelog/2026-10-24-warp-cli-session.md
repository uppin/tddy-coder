# 2026-10-24 — Warp in the Create session pane

The **Create session** pane's session-type toggle offers **Warp** after Muse Code. It shows no Model or
Provider field, and **Start New Session** is enabled once a project is chosen; the request sends
`sessionType: "warp-cli"` with `model: ""`. See [Session drawer § Session Types](../session-drawer.md#session-types)
and [Warp CLI session](../../daemon/warp-cli-session.md).
