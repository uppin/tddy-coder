# 2026-11-15 — Sessions can be named

A session can be given a name, which is its label on its drawer row and in the inspector ahead of the
derived one. The inspector's Details tab opens with it: double-click it or press **Rename**, then
**Enter** saves and **Escape** cancels; an empty name returns the session to its derived label. The
New-session form takes an optional **Name** for every session type but a tool session. A name is at
most 80 characters, on one line. See
[Session drawer § Session names](../session-drawer.md#session-names).
