# 2026-11-22 — Work queue tab and "With work queue"

A session that owns a work queue shows a Work queue tab in its inspector and opens on it; the drawer's
project row opens a queue in its owning session's tab. The New-session form starts a session with a queue
when "With work queue" is checked. See [Session drawer § Work queue tab](../session-drawer.md#work-queue-sidebar)
and [Create-session package](../create-session-package.md) (`#workqueue` 5/14, PR #1006).
