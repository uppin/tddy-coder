# 2026-10-29 — Clicking a Tddy Desktop notification opens its session

- **A click brings the window forward on that session.** Each notification carries the session it is
  about; a click on anything that names no session opens nothing.
- **Tauri 2.12.5 and `tauri-plugin-notification` 2.8.0**, the first plugin line that reports desktop
  clicks.
