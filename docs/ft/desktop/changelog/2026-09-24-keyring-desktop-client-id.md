# 2026-09-24 — A fresh Tddy Desktop install is ready to sign in

- **Sign-in is configured out of the box.** `./install --desktop` renders the Tddy Desktop GitHub
  OAuth App's public client id, so the installed application offers "Sign in with GitHub" by device
  code on first launch, with nothing edited by hand and no secret shipped. The first account to sign
  in from the application's window owns the install. See [Tddy Desktop](../tddy-desktop-tauri.md)
  § *What a fresh install signs in with*.
