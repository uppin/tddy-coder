# 2026-11-26 — One filesystem port for all disk I/O

No user-visible change: technical foundation. All disk I/O goes through the `Fs` port in the new
`tddy-fs` crate — real disk in production, in-memory in tests — and the crash-safe atomic file
write exists in exactly one implementation, which the session store and the credential vault both
use. See [the filesystem port](../../../packages/tddy-fs/docs/filesystem-port.md) (PR #1045).
