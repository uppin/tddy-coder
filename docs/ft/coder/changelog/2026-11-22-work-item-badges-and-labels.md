# 2026-11-22 — Agents label work items and mark them with keyed badges

A queue's agent can set labels on a work item (replacing the set) and put keyed badges on it in one of
four tones — `info`, `success`, `warning`, `danger` — with three new work tools; limits are refused
naming the limit. The derived internal status is unchanged. See
[PR stacking § Labels and badges on a work item](../pr-stacking.md#labels-and-badges-on-a-work-item-added-2026-11-22)
(`#workqueue` 7/14, PR #1008).
