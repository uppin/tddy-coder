# 2026-11-03 — Every CLI harness session can run its agent in tmux

**Run the agent in tmux** is offered for Cursor CLI, OpenCode, Muse Code and Warp sessions too, with claude-cli's start, delete, survive-the-daemon and re-attach behaviour. In tmux mode a harness runs as the session's OS user (Cursor too, which otherwise runs as the daemon user). A restarted daemon re-attaches any of them on the first stream without relaunching the agent. Warp's resume token still works: its tmux pane is kept after `warp` exits and the token is read from the final screen — on the agent's exit, never a client's, also when the exit happened with no client or no daemon attached. See [Cursor CLI § tmux mode](../cursor-cli-session.md#tmux-mode), [OpenCode § tmux mode](../opencode-cli-session.md#tmux-mode), [Muse Code § tmux mode](../muse-cli-session.md#tmux-mode) and [Warp § tmux mode](../warp-cli-session.md#tmux-mode).
