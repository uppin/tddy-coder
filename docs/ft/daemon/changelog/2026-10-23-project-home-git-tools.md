# 2026-10-23 — Project-home git tools

The project-home agent can commit and push another session's work in its project at any time, and
rebase, stash, reset, check out, clean or force-push it once that session is stopped — refused,
naming the session, while it is active. A conflicting rebase is undone and its files reported. See
[project concept § Git tools](../project-concept.md#git-tools).
