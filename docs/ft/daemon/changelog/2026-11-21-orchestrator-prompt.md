# 2026-11-21 — The orchestrator is told to run all coding through tracked tddy sessions

An orchestrator's role prompt opens as an orchestrator (a main's as the main session) and tells it to
do all coding through tddy sessions it starts and follows, to ask every child to report progress and
status over its back channel, to message children by their listed route, to check the base and read
trunk commits, and to ask for anything out of reach with `RequestPathAccess`. See
[Project concept § Role prompt](../project-concept.md).
