# 2026-11-03 — A tmux-run agent survives the daemon and is re-attached

A claude-cli session run in tmux now outlives its tmux client: daemon shutdown only detaches the main terminal, and a client that exits while the agent lives keeps the session's toolcall socket and LiveKit exposure. Resume of a session whose tmux session is alive re-attaches the main terminal instead of relaunching Claude (same pane pid); so does the first stream, input or history read of its `main` terminal, since such a session reads active and the web offers no Resume. A detached agent is watched every 10 s, and its session is cleaned up once its tmux session ends. A gone tmux session still resumes fresh. See [Claude CLI session § tmux mode](../claude-cli-session.md#tmux-mode-startsessionrequestrun_in_tmux--true) and [Terminal sessions](../terminal-sessions.md).
