# 2026-11-03 — A Claude CLI session can run its agent inside tmux

A claude-cli session created with **Run the agent in tmux** runs Claude in a tmux session of its own on the host (`tddy-<session id>`), as the session's OS user, with the session's main terminal attached to it — so it can also be attached from any terminal. The session records the tmux session and the agent's pane pid; Delete, daemon shutdown and Resume act on the agent and its tmux session, and tmux tabs keep their own sessions running. Refused together with the sandbox, the sandboxed codebase or a split placement. See [Claude CLI session § tmux mode](../claude-cli-session.md#tmux-mode-startsessionrequestrun_in_tmux--true) and [Terminal sessions](../terminal-sessions.md). Part of [#814](https://github.com/uppin/tddy-coder/pull/814) (`#tmux-agent` 1/3).
