## Responsibility

This PR owns the create-session SSH dropdown when placement is split (list from codebase host
B) and forwarding `ssh_config_host` on the workspace `StartSession` so B's RemoteShell runs
exec tools on T. Agent on A still uses LiveKit `ExecuteTool` to B.

## Boundaries

- Does **not** parse SSH config (n1) or implement `ListSshConfigHosts`.
- Does **not** implement `LocalShell`/`RemoteShell` or co-located dropdown sourcing (n2).
- Does **not** change `RemoteGitService` (n3).
- Does **not** absorb the split-room-on-restart sweep.
- Does **not** add cursor-cli split or jail-on-T.

## Dependencies

What each parent PR delivers that this PR consumes. These surfaces are **theirs to create**;
implementing one here collides with the PR that owns it.

| Parent node | What it delivers | How this PR consumes it | This PR does NOT |
|---|---|---|---|
| `n1` ssh-config | `ListSshConfigHosts` addressed by `daemon_instance_id` | split dropdown calls it for B | parse config, Hosts cell |
| `n2` exec | `ssh_config_host` field, RemoteShell, `create-session-ssh-config-select` (Host A) | retarget the same control; B uses RemoteShell | reimplement Shell, co-located start |
| `n3` remote-git | Serve-over-SSH | unused directly (specialized-agent clones already work once B Serves) | change pack spawn |

## Summary

Split create-session picks SSH destinations from the codebase host. The alias is applied on B,
not A.

## Background

OpenSSH reads **that host's** `~/.ssh/config`. A split session's SSH client is B.

## Technical Changes

### State A (Current)

Codebase host select exists. n2's SSH dropdown lists A's aliases. `workspace_start_request`
clones the operator request (`..req.clone()`). A split agent has no local repo.

### State B (Target)

When split, the same SSH control lists B's aliases. Workspace StartSession includes
`ssh_config_host`. B materializes on T and runs RemoteShell. A does not.

### Delta (What's Changing)

#### tddy-web
- **Implementation**: `ListSshConfigHosts` `daemon_instance_id` = codebase host when split.

#### tddy-session-lifecycle
- **Implementation**: workspace start keeps `ssh_config_host`; agent start does not apply it.
