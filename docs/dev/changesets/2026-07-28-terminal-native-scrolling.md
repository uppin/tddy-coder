# 2026-07-28 — **terminal-native-scrolling

**Type:** Feature

native ghostty `Scrollbar` on the page terminal and mouse-tracking (DEC 1006) gating, with the live terminal locked to `scrollback: 0` — no RPC change** — amends `terminal-replay-viewport`. **tddy-web**: the earlier "terminal-native-scrolling" amendment raised the live terminal to `scrollback > 0` to match native ghostty's primary screen; that was **reverted** because it reintroduced duplicate-pane accumulation for primary-screen-repainting TUIs and surfaced a blank-page-after-reconnect bug. The live terminal stays at **`scrollback: 0`** (the original no-duplicate-pane mitigation, stricter than native but the only way to keep the live pane duplicate-free for primary-screen repaints); a wheel-up fires the page forward-fill **immediately** (no post-connect scrollback to scroll through first). The **page terminal exposes a native `Scrollbar { total, offset, len }`** as the single source of truth for viewport position, in the same coordinate space as `scrollToLine` (matching ghostty `PageList.Scrollbar`): `total = getScrollbackLength() + rows`, `offset = max(0, getScrollbackLength() - getViewportY())`, `len = rows` — via a new `getScrollbar()` handle method and a hidden `terminal-page-scrollbar` mirror. **Forward-fill bounded by the current live tip** (not the stale anchor): after a reconnect the anchor captured at first connect becomes stale, and if the capture ring evicts past it `replay_from(0, anchor)` returns an empty range; the fill is bounded by the current cumulative output offset at fill time, and a fill that resolves with **no bytes written** (empty/evicted range) or that **errors** stays on the live pane — **no blank page swap**. **Mouse-tracking gating** (DEC 1006) routes the wheel to the TUI instead of the viewport (matching ghostty `isMouseReporting`), already implemented in `GhosttyTerminal.tsx` `onWheel` — now covered by tests (viewport stays pinned at scrollback 0). New pure helper `src/lib/terminalScrollbar.ts` `computeScrollbar(scrollbackLength, viewportY, rows) → { total, offset, len }`. **No proto/RPC/daemon change** — the lazy forward-fill wire contract is unchanged. Tests: bun `terminalScrollbar.test.ts` (6) for `computeScrollbar`; Cypress `GhosttyTerminalGrpcLazyHistory.cy.tsx` + driver extended with scrollback-0, native-Scrollbar, mouse-tracking, and blank-reconnect regression tests (empty fill, error fill, stale-anchor-eviction) — 18 passing.
