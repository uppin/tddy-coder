# 2026-07-23 — **session-activity-streaming-mode

**Type:** Feature

stream only new agent-activity records + structured tool input/output** — `StreamSessionActivity` gains a `StreamMode` request flag (`SNAPSHOT_THEN_LIVE` default replays the coalesced history then tails live; `LIVE_ONLY` skips the snapshot so a re-subscribing client avoids re-downloading up to 500 full records), honoured identically by the **tddy-daemon** gRPC handler and the **tddy-coder** LiveKit participant (unknown/omitted mode → snapshot-then-live). `AgentActivityRecord.input`/`result` move from opaque JSON strings to structured `google.protobuf.Value` on the wire (`serde_json::Value` in **tddy-core**), carrying object/array/string/scalar output faithfully (`Value`, not `Struct`); **tddy-service** adds the shared `json_to_proto_value` + `agent_activity_to_proto`. The `ReportAgentActivity` hook write-path stays string and is parsed server-side (empty → unset, else parse-or-string) via the shared `tddy_core::agent_activity::parse_activity_json`; **tddy-web** `useSessionActivity(mode?)` keeps the snapshot default and the detail dialog renders the structured value. Back-compat via the enum zero-value; on-disk `agent-activity.jsonl` format changes (legacy string rows skipped on read). Tests: tddy-service 68 (incl. 7 converter), tddy-core agent_activity 10, tddy-daemon agent_activity 9, tddy-coder session_participant 27, Cypress `AgentActivityAcceptance` 11; clippy `-D warnings` clean.
