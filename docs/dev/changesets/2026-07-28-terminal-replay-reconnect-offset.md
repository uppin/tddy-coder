# 2026-07-28 — **terminal-replay-reconnect-offset

**Type:** Feature

`StreamTerminalOutput` gains a `StreamReplayMode` (`TAIL` default / `FROM_OFFSET`); a reconnecting terminal resumes by offset instead of re-replaying the whole retained buffer, and a transient transport blip no longer evicts the runtime** — amends `terminal-replay-viewport`. **tddy-service**/**tddy-terminal-rpc**: `StreamTerminalOutputRequest` + the bidi `SessionTerminalInput` open frame gain `mode` (`StreamReplayMode`) + `from_offset`; new `StreamReplayMode` enum (`STREAM_REPLAY_MODE_TAIL = 0` default / `STREAM_REPLAY_MODE_FROM_OFFSET = 1`). `TAIL` (first connect) sends the mode prologue + current last-frame tail chunk, resizes the PTY, drains the pre-resize broadcast, then live; `FROM_OFFSET` (reconnect) sends the mode prologue + chunked catch-up via `replay_from(from_offset, tip, …)` until `at_end`, then live — no tail chunk, no PTY resize/drain, so a terminal that already holds state up to `from_offset` receives only the bytes it missed (no duplicate content). **tddy-terminal-rpc**: `bridge.rs` extracts the shared `open_replay_ack_live` sequence (used by both the split `StreamTerminalOutput` and the bidi `StreamSessionTerminalIO`) and adds the `FROM_OFFSET` catch-up branch. **tddy-daemon**/**tddy-coder**: `stream_terminal_output` / bidi delegate `mode`/`from_offset` to the bridge. **tddy-tools**: `pty_relay.rs` arg dispatch updated. **tddy-web**: `GrpcSessionTerminal.client` widens to `ConnectionClient | null` — a **null client** (transient transport blip) **pauses** the terminal (mounted, scrollback and ghostty instance survive, input queued) and resumes with `FROM_OFFSET` when a non-null client returns; only a stream-end with a **valid** client (real `pty_done`) evicts the runtime. It tracks the cumulative output offset (`currentOffsetRef`) and sends `FROM_OFFSET` with the tracked offset on reconnect (no duplicate replay). Tests: Cypress `GrpcSessionTerminalResume.cy.tsx` (reconnect resume-by-offset + null-client pause); Rust `tddy-terminal-rpc/tests/bridge.rs` (FROM_OFFSET catch-up); `tddy-daemon`/`tddy-coder` terminal acceptance suites green.
