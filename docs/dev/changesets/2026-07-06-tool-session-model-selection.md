# 2026-07-06 — **tool-session-model-selection

**Type:** Feature

pick the backend model when creating a tddy-coder session** — the web `CreateSessionPane` gains a Model `<select>` for **tool** (tddy-coder) sessions as well as **claude-cli**, sourced on demand from a new `ListAgentModels(agent, daemon_instance_id)` RPC (`tddy-service` `proto/connection.proto` + regen Rust/`connection_pb.ts`; adds `ModelInfo`, `ListAgentModelsRequest/Response`; reuses `StartSessionRequest.model` field 8, now populated for tool sessions too). One catalog mechanism, two sourcing strategies: `tddy-core` adds `BackendModel`/`BackendModels` + an async `CodingBackend::list_models()` (default = curated) with `AnyBackend`/`SharedBackend` dispatch — `cursor` enumerates via `<bin> --list-models` (parses `id - label` + `(current, default)`), `claude-acp`/`codex-acp` run an ephemeral ACP `initialize`+`new_session` and read `SessionModelState.available_models` (via pure `acp_models_from_session_state`, no longer discarding `.models`), while `claude`/`codex`/`stub` use curated lists (`curated_models_for_agent`) and the `claude-cli` pseudo-agent uses `claude_cli_models()`. `tddy-tools` adds a `list-models --agent <id>` subcommand printing the `{models,default_model}` JSON contract (`render_models_json`); the daemon's `ListAgentModels` handler shells out to it (`parse_agent_models_json`), caches per (agent, daemon, **OS user** — catalogs are account-specific) with a short TTL, and runs the probe as the user with `current_dir=$HOME`; `StartSession`'s tool branch threads `req.model` → `SpawnOptions.model` → `--model` (`spawner.rs`/`spawn_worker.rs`, `build_spawn_request`). A failed probe surfaces as a `BackendError` → RPC error → inline error in the form with the Model select empty and Create disabled — **no `default_model_for_agent` fallback**; the chosen model is single & session-wide (seeds `context["model"]`, recipe per-goal `default_models()` do not override). Tests: `tddy-core` 236/236 (cursor parser, curated catalogs, ACP mapping incl. no-fallback-on-missing-state), `tddy-tools` 29/29 (`render_models_json`), `tddy-daemon` 250 (spawn `model` threading + `parse_agent_models_json` incl. malformed-probe error; 1 pre-existing sandbox-runner failure unrelated), Cypress `CreateSessionModelSelectionAcceptance` 7/7 + `CreateSessionPane` 29/29. **Known limitation (`[~]`):** `CLAUDE_CLI_MODELS` (`packages/tddy-web/src/constants/claudeCliModels.ts`) is removed from `CreateSessionPane` but **retained** for the out-of-scope legacy `ConnectionScreen` inline form (removal deferred until it migrates to `ListAgentModels`). Out of scope: `ConnectionScreen`, changing a running session's model (`SetSessionModel`), per-goal UI overrides.
