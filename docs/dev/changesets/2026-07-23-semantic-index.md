# 2026-07-23 — **semantic-index

**Type:** Feature

optional per-session code embedding index + gated `SemanticSearch` for managed-codebase sessions** — a **Semantic index** toggle on managed `claude-cli`/`cursor-cli` sessions makes the daemon index the worktree into a per-session `sqlite-vec` DB (`<session_dir>/semantic-index.db`) **before** the agent launches, blocking start and aborting on failure (no fallback). New crate **`tddy-semantic-index`**: `chunk_worktree`, a `rusqlite`+`sqlite-vec` `SemanticIndexStore` (vec0 KNN), a blocking `SemanticIndexTask` (`tddy-task`), a `SemanticSearchEngine`, and an injected **`Embedder`** trait — production `LocalEmbedder` (candle `all-MiniLM-L6-v2`, 384-dim, mean-pool+L2-normalize, hf-hub fetch-cache) behind the non-default **`local-model`** feature; `production_embedder(data_dir)` errors without it. **`tddy-daemon`** `semantic_index` module (`semantic_index_db_path`/`semantic_index_env`/`run_semantic_index_blocking`) is wired into all four managed start paths (claude+cursor × sandboxed+non-sandboxed), injecting `TDDY_SEMANTIC_INDEX_DB`; a non-default daemon `local-model` passthrough feature gates the embedder. **`tddy-sandbox-recipes`** adds `effective_replaced_tools` (SemanticSearch joins the replaced set when indexing is off); **`tddy-sandbox-runner`** applies it in `spawn_claude_pty` keyed off the injected env — so `SemanticSearch` is hard-disabled for un-indexed sandboxed-claude sessions (cursor/non-sandboxed rely on the tool's call-time "no index" error). **`tddy-tool-engine`** `SemanticSearch` now reads `TDDY_SEMANTIC_INDEX_DB` and errors without an index (ripgrep fallback removed). **`tddy-service`** proto `StartSessionRequest.semantic_index` (regen Rust + `connection_pb.ts`); **`tddy-web`** adds the toggle. Tests: `tddy-semantic-index` 9 (store/index-task/search/embedder-factory) + gated model smoke, `tddy-sandbox-recipes` gating 3, `tddy-tool-engine` no-index 1, `tddy-daemon` `semantic_index_wiring` 3, Cypress `CreateSessionSemanticIndex` 5. Follow-ups: `SemanticSearch` populated-index query path (needs the embedder wired into the tool), `./release`/`./install` enabling `local-model`, cursor/non-sandboxed-claude allow-list gating.
