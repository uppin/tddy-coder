# 2026-07-28 — **terminal-replay-viewport

**Type:** Feature

overlay double-buffer scroll-up history; the Ghostty shared component owns the lazy history paging end-to-end** — `GhosttyTerminalGrpc` renders **two interchangeable, overlaid ghostty-web terminals** sharing one rect: a live terminal (`scrollback: 0`, always mounted & streaming) and an older-history "page" terminal (`scrollback > 0`, `testId="ghostty-terminal-older"`, read-only). On a scroll-up-at-top gesture (or the "Load earlier output" affordance) the page terminal is **forward-filled in the background** from offset `0` toward the anchor (append-only, no resets) while a **loading indicator** is shown; once the fill completes the two terminals **switch places** (the page terminal becomes foreground, scrollable through the retained capture; the live terminal stays mounted underneath and current). "Back to live" (or a scroll-down-at-bottom gesture on the page pane) swaps back instantly. The live terminal stays at `scrollback: 0` (preserving the no-duplicate-pane fix for periodic TUI re-paints). It captures the `endOffset` anchor (in state) from the initial `StreamTerminalOutput` frame and runs the forward fill via a `historyFetcher` prop (one `GetTerminalHistory`-shaped call per chunk, advancing `fromOffset` to each chunk's `endOffset` until `atEnd = true`); capture-phase wheel listeners on both panes fire before ghostty-web's own wheel handler. **tddy-web**: `GhosttyTerminal` gains `scrollback` (default `0`) and `testId` props + `scrollToTop()`/`scrollToBottom()`/`isPinnedToBottom()` handle methods; `GhosttyTerminalGrpc` widens `GrpcStream.onMessage` to the full frame `{ data, endOffset, atOldest }`, adds `historyFetcher`, owns the overlay double-buffer (`view`/`loading`/`filled` state, live + page panes, loading indicator, swap, `view-history`/`back-to-live` affordances, forward fill, capture-phase wheel gestures); `GrpcSessionTerminal` builds `createForwardHistoryFetcher(client, …)`, forwards full frames, removes `onRegisterLoadOlderHistory` + `historyLoaderRef`; the backward `TerminalHistoryLoader` rebuild controller is replaced by `TerminalHistoryForwardLoader` (`terminalHistoryLoader.ts`). **Proto (not backward-compatible — `GrpcSessionTerminal` is the only consumer, updated in lockstep)**: `GetTerminalHistoryRequest` switches from `before_offset` to `from_offset` + `until_offset`; `TerminalHistoryChunk` gains `at_end` (`terminal_session.proto` + `connection.proto`, stubs regenerated). **tddy-task**: `TerminalCapture::replay_from(from_offset, until_offset, max_bytes)` forward replay (TDD `terminal_capture_replay_from`). **tddy-terminal-rpc**: `serve_get_terminal_history_with` uses `replay_from` and maps `at_end`; bridge tests updated. **tddy-daemon**/**tddy-coder**: `get_terminal_history` handlers map `from_offset`/`until_offset`.
