# 2026-08-31 — Rust code analysis and restructuring on `tddy-tools`

**Type:** Feature

two new workspace libraries (`tddy-code-analysis`, `tddy-code-restructuring`) expose deterministic Rust CRAP targeting and plan-driven refactors on the existing `tddy-tools` binary: `analyze {coverage,report,duplicate-tests}` and `restructure {apply,status,check,anchors,verify}`. Analysis captures llvm-cov per-test artifacts, scores cyclomatic complexity with `syn`, joins CRAP on `(file, declaration line)`, writes HTML reports, and detects duplicate/subset tests from region bitsets. Restructuring replays JSONL intents (no source text) through rust-analyzer via `tddy-lsp` — one server per workspace, no private rust-analyzer spawn — with seven Rust operations and journal/ledger/overlay apply. `tddy-lsp` gains `request_raw`/`notify_raw` for the sync bridge; typed assist APIs are deferred. Agent skills `analyze-code-issues` and `code-restructuring` live under `.agents/skills/`; nix dev shell adds `llvm-tools-preview`.
