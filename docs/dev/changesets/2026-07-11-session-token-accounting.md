# 2026-07-11 — **session-token-accounting

**Type:** Feature

per-conversation token accounting + conversation listing** — a `tddy-sandbox-app` session lists every conversation (main Claude agent, its nested Task-tool subagents, and tddy `subagent_*` conversations incl. Ollama) and accounts input/output/total tokens + turns per conversation, printing a per-agent breakdown to stderr at session end. `tddy-discovery`: `TokenUsage` + `usage` parsing on `ChatCompletionResponse`, per-turn/cumulative usage on subagent sessions. `tddy-core`: agent-neutral `token_accounting` (`ConversationRecord`, `format_token_summary`) + Claude-backend readers `read_claude_transcript_usage`/`read_claude_subagent_usages` (nested Task subagents under `<session_id>/subagents/`; `cache_*` excluded). `tddy-tools`: `subagent_list` MCP tool, `usage` in `subagent_prompt` results, `TDDY_TOOLS_ACCOUNTING_FILE` writer. `tddy-sandbox-runner`: wires the accounting file into the in-jail MCP spawn. `tddy-sandbox-app`: `print_token_summary` merges the sources to stderr. RPC/backend layer only (no web/TUI); tokens only (no cost). ⚠️ Live end-to-end stderr summary against a real Ollama session not yet exercised.
