# 2026-07-16 — **session-terminal-tabs

**Type:** Feature

multiple terminals per session with top tabs (both transports)** — a terminal tab bar in the session detail pane switches between the coding agent and N interactive bash terminals; the Agent tab (reserved `"main"`) is fixed, `+` opens closable bash tabs, backgrounded terminals stay mounted and keep streaming. Reuses the existing `ConnectionService` terminal RPCs (`StartTerminalSession`/`StopTerminalSession`/`ListTerminalSessions` + `terminal_id`-addressed `StreamTerminalOutput`/`SendTerminalInput`) — no proto changes. New shared **`tddy-pty`** crate: PTY runtime + registry extracted from `tddy-daemon` (`PtyRuntime`/`open_pty_and_pump`/`PtyRegistry`/`PtyControl`); the daemon keeps OS-user impersonation over a thin adapter (`resolve_final_argv_env`). `tddy-coder`'s participant gains a `TerminalManager` (spawns the user's passwd login shell via `tddy-pty`) + `handle_rpc` arms for the terminal RPCs (`main` stays the VirtualTui; `Stop("main")` rejected). `tddy-web`: `SessionTerminalTabs` + `useSessionTerminals`; `terminalId` threaded through `GrpcSessionTerminal`; one mounted pane per terminal with per-terminal disconnect (a shell exit drops only its tab). Bash terminals resolve the shell from passwd (`getpwuid_r`/`getpwnam_r`), not the nix-polluted `$SHELL`. Tests: Cypress `SessionTerminalTabsAcceptance` (5), coder participant terminal-RPC tests (6) + shell-selection units (4), `tddy-pty` units (2).
