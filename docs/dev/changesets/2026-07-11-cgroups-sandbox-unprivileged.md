# 2026-07-11 — **cgroups-sandbox-unprivileged

**Type:** Feature

Linux cgroups sandbox under an unprivileged `User=tddy` daemon (`Delegate=yes` + AppArmor)** — makes the Linux cgroups jail work when `tddy-daemon` runs as the unprivileged `tddy` user (root not an option) without ever degrading to an unconfined process. Two root-cause fixes: (1) the userns precondition is now a **functional probe** (`probe_unprivileged_userns` forks a child that does the real `unshare(CLONE_NEWUSER)` + `setgroups=deny` + uid/gid-mapping writes, async-signal-safe) instead of reading `apparmor_restrict_unprivileged_userns` — the only way to see a per-binary AppArmor grant (Ubuntu 24.04 gates the *mapping* writes, not `unshare`); root short-circuits; pure core `userns_available_from(is_root, probe)`. (2) the cgroup base is **derived at runtime, config-overridable, never hardcoded**: `detect_and_prepare_base` (`OnceLock`) reads `/proc/self/cgroup` + `/proc/self/mountinfo` (config `base_path` → `0::` line joined with cgroup2 mount root → `/sys/fs/cgroup`), relocates the daemon's own TGID into a `supervisor` leaf and enables `memory cpu pids` in the base `subtree_control` (cgroup v2 no-internal-processes rule), then per session creates a unique `tddy-<name>-<seq>.scope` (`AtomicU64` seq). `tddy-sandbox` adds an additive Default-empty `SandboxPlan.cgroup` (`CgroupConfig`) so macOS/QEMU ignore it; `tddy-daemon` maps an optional `sandbox_cgroup:` section (`SandboxCgroupConfig`) threaded into `build_sandbox_plan` at 3 spawn sites. Base detection / self-relocation / scope creation / child-move are fail-fast (`Unsupported`); only controller-enable + limit-writing stay best-effort. `./install` flips the default systemd unit to `User=tddy`/`Group=tddy`/`Delegate=yes`/`AppArmorProfile=tddy-daemon`, creates the (configurable) service user, chowns log/auth dirs, and ships+auto-loads the `packages/tddy-daemon/apparmor/tddy-daemon` profile before start (`INSTALL_DAEMON_USER=root` restores root mode). Tests: tddy-sandbox-cgroups 13 pure-unit + 3 seam, tddy-daemon config 1 (host-touching probe/relocation + `jail_smoke`/`stdio_piping` self-skip without a delegation-capable host); clippy/fmt clean. Follow-ups: per-session `rmdir` of empty scope dirs; `pivot_root` read-only-root confinement; end-to-end on-host deploy check deferred.
