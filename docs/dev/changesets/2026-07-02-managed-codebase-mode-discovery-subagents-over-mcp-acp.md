# 2026-07-02 — Managed-codebase mode + discovery subagents over MCP (ACP-shaped)

**Type:** Feature

formalizes the existing "remote codebase" proxied-tools concept as user-facing **managed-codebase mode** (`REMOTE_APPENDIX`/`SANDBOX_REMOTE_APPENDIX` prose now says "MANAGED"; internal identifiers/env vars unchanged for wire stability) and adds pluggable **discovery subagents**: `tddy-discovery::subagent` (`SubagentSession` trait, `CodebaseAccess { Local | Managed }`, stateful `FastContextSession`, `SubagentRegistry`); `tddy-tools`' `PermissionServer` exposes three ACP-shaped MCP tools (`subagent_new_session`/`subagent_prompt`/`subagent_cancel`, mirroring `session/new`/`session/prompt`/`session/cancel`) gated on `TDDY_SUBAGENT`, backed by a process-wide session table so a conversation survives across separate `tools/call` invocations with the caller choosing the `sessionId`; `tddy-sandbox-app` gains `--codebase-mode {mounted,managed}` (supersedes `--remote-codebase`, kept as a working alias) and `--discovery-subagent`/`--fastcontext-*` flags, wired end-to-end through `main.rs` → `SpawnParams` → sandbox-runner env → `tddy-sandbox-runner`'s `append_claude_mcp_args` (now `subagent_enabled: bool`) so a sandboxed Claude's `--allowedTools` actually includes the subagent tools.
