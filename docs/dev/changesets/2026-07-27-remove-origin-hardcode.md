# 2026-07-27 — **remove-origin-hardcode

**Type:** Bug Fix

no code path assumes the `origin` remote; `origin` survives only as the last-resort fallback** — `validate_integration_base_ref` / `validate_chain_pr_integration_base_ref` (tddy-core) accept any safe `<remote>/<path>` (pure string rules, no git probe; error strings drop `origin/`). New `detect_default_remote_name(repo_root)` runs `git rev-parse --abbrev-ref @{upstream}` and splits on the first `/` (returns `None` on detached HEAD / missing upstream / git error); `resolve_default_integration_base_ref_with_remote(repo_root, preferred_remote)` chooses `preferred_remote` → detected → `origin`, then `git fetch <remote>` and probes `<remote>/master` → `<remote>/main` → `refs/remotes/<remote>/HEAD` (bare `resolve_default_integration_base_ref` delegates with `None`). `fetch_integration_base` / `fetch_chain_pr_integration_base` split the validated ref on the first `/` into `(remote, path)` and run `git fetch <remote> <path>`; `push_new_branch_to_origin` → `push_new_branch_to_remote(worktree_dir, branch, remote)` (legacy wrapper retained); `list_recent_remote_branches*` take a `remote` and filter `<remote>/`; `local_branch_name_for_remote(reference, remote)` strips one leading `<remote>/` (legacy `local_branch_name` strips `origin/`); `DOCUMENTED_DEFAULT_INTEGRATION_BASE_REF` renamed `FALLBACK_DEFAULT_INTEGRATION_BASE_REF`. `session_chain::resolve_chain_integration_base_ref_from_parent_session` builds `<remote>/<trimmed>` from the child project's resolved default remote. **tddy-daemon**: `ProjectData.remote_name: Option<String>` (serde skip-if-none); `connection_service` threads the resolved remote through push, list, repoint, spawn-branch (now `effective_spawn_branch(..., remote)`), and telegram call sites. **tddy-service**: `proto/connection.proto` adds `ProjectEntry.default_remote = 7` and `ListProjectBranchesResponse.default_remote = 2`, populated from `effective_remote_name_for_project`. **tddy-web**: `localBranchName(reference, remote)` strips one leading `<remote>/`;
