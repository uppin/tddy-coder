# 2026-07-01 — Configurable FastContext model + plain-mode free-prompting completion

**Type:** Feature+Fix

`--fastcontext-model`/`fastcontext_model` config lets `FastContextBackend` target any OpenAI-compatible model tag (e.g. a locally-served Ollama model), not just the hardcoded `microsoft/FastContext-1.0-4B-RL` default. Separately, fixed `tddy-coder`'s plain (non-TUI) CLI crashing with `Error: no pending questions` on any single-shot `--recipe free-prompting` turn: `BackendInvokeTask` now persists the no-submit `Continue` response into `context["output"]` (previously only `TaskResult.response`, which `FlowRunner` discards), and `run_full_workflow_plain`/`run_goal_plain` now distinguish a genuine clarification pause from `FreePromptingRecipe`'s single no-successor `prompting` task (which `FlowRunner` also reports as `WaitingForInput`) via a `pending_questions` presence check, printing the response and completing instead of erroring.
