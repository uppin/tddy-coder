# 2026-06-28 — Linux rootless cgroups sandbox + shared runner/host-relay + sandbox flag

**Type:** Feature

sandbox brought to Linux (previously macOS-only). New `tddy-sandbox-runner` crate extracts the in-jail runner + host-side `run_host_relay` (parameterized by `HostToolHandler`) out of `tddy-sandbox-darwin`/`tddy-daemon`; adds AF_UNIX gRPC transport (`--grpc-uds`/`connect_sandbox_client_uds`) so the control channel survives a network namespace. New `tddy-sandbox-cgroups` crate: rootless `spawn` (unprivileged userns + network ns with loopback-only egress + private mount ns + cgroup v2 limits; fails fast — no unconfined fallback). `tddy-daemon` `spawn_sandbox_runner` dispatches darwin/cgroups by target OS + dials UDS on Linux; the in-jail CONNECT shim now waits for the host to attach (fixes a startup race). `tddy-sandbox-app` + `tddy-testing-commons` collapsed onto `run_host_relay`. Sandbox toggle added to the tddy-web new-session form. Feature [claude-cli-session.md](../../ft/daemon/claude-cli-session.md); architecture [tddy-sandbox architecture](../../../packages/tddy-sandbox/docs/architecture.md). PR [#242](https://github.com/uppin/tddy-coder/pull/242). Follow-ups: `pivot_root` fs write-confinement, config-driven cgroup limits.
