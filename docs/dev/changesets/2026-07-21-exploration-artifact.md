# 2026-07-21 — **exploration-artifact

**Type:** Feature

persisted code-discovery `exploration.md` reused across workflow steps** — an optional `exploration` string on the plan and bugfix-`analyze` submit schemas (`generated/tdd/{plan,analyze}.schema.json`); the engine persists it verbatim as `session_dir/artifacts/exploration.md` (plan agent stays read-only; blank/absent → no file) via `writer::write_exploration_file`/`EXPLORATION_BASENAME`, and bugfix `apply_analyze_submit_to_changeset` writes it too. Registered in `known_artifacts()` for tdd/tdd_small/bugfix/grill-me so it rides the `<context-reminder>` header, which is extended past acceptance-tests/red to green/evaluate/demo/validate/refactor (`tdd/hooks.rs`, `hooks_common.rs`, `tdd_small/hooks.rs`, threading `manifest`). Planning prompt documents the field (Code Map file:line refs, mermaid, Documentation, Conventions & Gotchas); acceptance-tests/red/green prompts instruct read-before-explore + append-as-living-doc; grill-me `create_plan_system_prompt` writes the file directly. `tddy-tools` re-embeds the schemas (no source change).
