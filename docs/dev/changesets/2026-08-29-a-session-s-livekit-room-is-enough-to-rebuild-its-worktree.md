# 2026-08-29 — a session's LiveKit room is enough to rebuild its worktree

**Type:** Feature

the room broadcast *that* a checkout moved and nothing more: `AgentActivityRecord` carried a tool name and its raw input but no commit, so a consumer could not know what state an edit applied to, and `ReadWorktreeFile` returned `string content_utf8`, hard-failing on any non-UTF-8 byte and truncating at 1 MiB. Together those made a mirror not slow but *wrong*. Each poll tick now stages a WIP tree — the agent's index copied to a scratch index inside the git dir, `add -A`, `write-tree`, so the agent's own index is never touched and git's stat cache means a tick hashes only what moved — and publishes it as `refs/tddy/session/{id}/wip`, a commit parented on the measured `HEAD`, authored by a fixed `tddy-daemon@tddy.invalid` identity because the object is a machine-made snapshot rather than signed work, and kept under `refs/tddy/` so it is never a branch an agent sees, pushes to or can check out by name. That ref is what makes reconciliation an ordinary `git fetch`: a mirror is a clone of the same repository, so git moves only the objects it lacks, where a cumulative patch would resend the whole dirty tree every time a client fell a tick behind. Alongside it a ring of `git diff --binary` patches between consecutive ticks, bounded on **both** axes (`SESSION_DELTA_RING_TICKS` 64, `SESSION_DELTA_RING_BYTES` 16 MiB) because a tick count bounds a busy session only if its patches are small and a byte budget bounds one enormous change but not a million tiny ones. `tick_delta` returns `None` rather than an empty delta whenever a tick cannot be *described*, and that distinction is the whole safety property — an empty patch lets a client record the tick and advance its sequence, so an empty patch standing in for a failure is a change the mirror never learns about and never reconciles. Records gain `head_commit`, `activity_seq` and `changed_paths` (all `#[serde(default)]`, so existing `agent-activity.jsonl` still deserializes) and are broadcast on the new `session.activity` topic; a call's delta is narrowed to the paths it declared and the tick's residual carries what no call claimed, so every call scope plus the residual reconstructs the whole tick. Two server-streaming RPCs serve it: `StreamAgentActivityDelta` (three scopes, an unknown `call_id` distinguished from one aged out of the ring) and `StreamReadWorktreeFile` (byte-exact, no 1 MiB truncation). New **`tddy-session-sync`** consumes all of it into a fully managed mirror parked with `HEAD` on the session's own commit and the uncommitted edits in the working tree — the only place every delta applies — de-duplicating per tick rather than per call, since several calls share a poll window and asking for each call's scope would apply the first and silently drop the rest along with the residual. Its destination is owned: a marker file, local edits discarded, and both a non-empty unmarked directory and one marked for another session refused rather than adopted. Deliberately **not** unit-tested on patch text — the delta is `git diff --binary` output and applying it is `git apply`, so asserting on the text would pin git's formatting; every assertion is on resulting worktree bytes, up to a six-test suite over a real LiveKit server, a real daemon and the real git transport. ⚠️ Known and recorded in `docs/dev/TODO.md`: `StreamReadWorktreeFile` is served but never called, so a `.gitignore`'d path is absent from the mirror rather than fetched; a room's first delta is numbered 0, which is also the wire's "no tick yet" sentinel, so a session's first change arrives at the next reconcile instead of from the delta carrying it; the client's first attach fetches the WIP ref once with no retry where the daemon's in-process sibling waits for it; `StreamReadWorktreeFile` duplicates `StreamReadHostDocument`'s SESSION_WORKTREE scope (shared byte reader and guards, so they differ only in addressing); and the client holds `LIVEKIT_API_SECRET`, a real widening of the trust surface forced by `MintLiveKitToken` granting only the common room.
