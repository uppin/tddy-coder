# 2026-07-01 — Remote-codebase dynamic tool catalog wiring + sandbox app follow-up + sandbox PTY session-end fix

**Type:** Feature+Fix

`tddy-tools` `PermissionServer`: `exec_tool_catalog()`/`dynamic_tool_router(catalog)` wire the 10 documented cursor tools (Read/Write/StrReplace/Delete/Grep/Glob/Shell/Await/ReadLints/SemanticSearch) into the live `#[tool_handler]` `ServerHandler` via `#[tool_handler(router = self.tool_router)]` (the macro's default expansion called the static `Self::tool_router()`, ignoring the instance field — Claude Code saw only 3 static tools instead of 13); `tool_names()` + `PermissionServer::new()` merge wiring. `tddy-sandbox-app`: `--remote-codebase` flag (repo not mounted into the jail; Claude reaches it only via `mcp__tddy-tools__*`) and persistent `--claude-home-dir`/`TDDY_SANDBOX_CLAUDE_HOME` (read-write, reused across restarts) with one-time credential/install seeding, for manually exercising the dynamic-tool-wiring fix end-to-end.
