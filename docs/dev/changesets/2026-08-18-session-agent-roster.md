# 2026-08-18 — **session agent roster

**Type:** Feature

attach any number of agents, from any daemon** — a session's specialized agents become a revisioned roster mutated on a live session, addressable as `name@daemon_instance_id`, replacing a fixed list of names frozen at spawn and every hardcoded builtin (`fastcontext`, `--fastcontext-*`, `TDDY_SUBAGENT`, the action-author/coder `replaces` roles). The roster is the single source of truth on the wire, at rest, and in the in-jail registry rebuilt from `StreamSessionAgents`. A remote agent's def is resolved on its owning daemon; its loop runs there against a clone kept current by the in-process session-worktree-sync mirror, and its mutating tools proxy back to the facilitating daemon — one clone per (session, owning daemon). The owning daemon joins the session room with a **facilitator-minted, scoped, short-TTL admission token** (no self-mint); a full-rejoin re-admit loop preserves clone state across reconnects, and revocation (last detach / session delete) stops the mirror cleanly (`SessionAdmissionRegistry` + `SessionAdmissionService.AdmitOwningDaemon`). Roster and conversation RPCs reach a jailed agent over the sandbox `SessionChannel` multiplexed by `request_id` (`RpcRequest`/`RpcStreamFrame`), so a lifetime-long roster stream does not occupy the `ExecuteTool` slot; `tddy-sandbox-runner` dispatches to an injected `HostRpcHandler`, and `tddy-daemon`'s `DaemonRpcHandler` recovers the `Arc<ConnectionServiceImpl>` through a self-handle. `replaces`/`tools` are frozen into the entry at attach; a replaced tool is refused at call time; clone readiness is pushed (`ReportAgentCloneState`); `RosterCurrency` distinguishes a roster that never received a frame (does not enforce withdrawal) from one that went stale (still enforces). Web gains a fanned-out agent picker and an Agent roster pane.
