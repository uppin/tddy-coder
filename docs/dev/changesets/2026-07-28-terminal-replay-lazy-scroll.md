# 2026-07-28 — **terminal-replay-lazy-scroll

**Type:** Architecture Change

`StreamTerminalOutput` sends the current last frame first (tagged with absolute `start_offset`/`end_offset`/`at_oldest`); older history is fetched on demand via the new `GetTerminalHistory` RPC as the user scrolls up, one chunk per call chaining anchors until `at_oldest`** — the duplicated PTY-over-RPC bridge logic (replay, ACK interleave, resize/drain, input forward, exit) is unified into a new shared `tddy-terminal-rpc` crate behind `TerminalSession`/`TerminalSessionStore` async traits; `tddy-daemon` (`DaemonTerminalSessionStore`) and `tddy-coder` (`CoderTerminalSessionStore`) adapt their `PtyHandle`s and delegate `StreamTerminalOutput`/`GetTerminalHistory`/`SendTerminalInput` to it. **tddy-task**: `TerminalCapture` gains absolute byte-offset tracking + `replay_last`/`replay_before` (TDD `terminal_capture_offsets`). **tddy-service**: `connection.proto` additive — `SessionTerminalOutput` +`start_offset`/`end_offset`/`at_oldest`, new `GetTerminalHistory` RPC + `GetTerminalHistoryRequest`/`TerminalHistoryChunk` (RPCs stay on `ConnectionService` — no service split, backward-compatible; new fields default to 0). **tddy-daemon**: `connection_service` claude-cli `StreamTerminalOutput` rewritten + new `GetTerminalHistory` delegate to the bridge; tonic adapter wired; sandbox path preserved; `terminal_session_adapter.rs` added. **tddy-coder**: `session_participant` `StreamTerminalOutput` + new `GetTerminalHistory` arms delegate to the bridge; `terminal_session_adapter.rs` added. **tddy-tools**: `pty_relay.rs` shrunk to arg dispatch over `tddy-terminal-rpc::local_pty_relay`. **tddy-sandbox-runner**: `SessionTerminalOutput` literals updated for new fields. **tddy-web**: regenerated gRPC stubs; new `TerminalHistoryLoader` client primitive (`src/lib/terminalHistoryLoader.ts`) + 5 bun unit tests; `GrpcSessionTerminal` captures the anchor from the initial frame and exposes `onRegisterLoadOlderHistory`; in-memory Cypress backend `getTerminalHistory` + offset metadata; new `GrpcSessionTerminalLazyHistory.cy.tsx` (2 tests); fixed 3 pre-existing `UploadProgressProvider` test-harness bugs (`GrpcSessionTerminalResize`/`Disconnect`/`SendErrors`).
