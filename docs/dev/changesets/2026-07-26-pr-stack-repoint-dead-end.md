# 2026-07-26 — **pr-stack-repoint-dead-end

**Type:** Fix

a stranded planned PR can be repointed, and a blocked row stops hiding itself** — a planned PR whose predecessor's PR merged and whose branch was then deleted on `origin` was unrecoverable: the row **replaced** its own contents with a "Missing branch" chip (D10), the Repoint control was gated on the plan's `pr_status.phase == "merged"` — a field the orchestrator agent writes, so merging on GitHub without an assess pass leaves it reading `open` — and `repoint_planned_pr_node` would have refused anyway with `node '<id>' has no branch to repoint`, which is exactly the never-started node stranded behind the deleted base. Now: a blocked row renders everything it has plus a new base-branch line, with Start-session **disabled** (blockers as its tooltip) beside a warning listing each reason (**D16, reversing D10**); Repoint is offered for **any** unresolvable base (D17) and reads "Repoint to `<target>`", sending that target as the new `RepointPlannedPrRequest.target_base_branch` so the daemon retains exactly the parents owning it — **collapsing the node to a single parent by intent** (D18, chosen over a daemon-side git probe that cannot distinguish "absent from origin" from "could not tell"); a branchless node is a **plan-only** repoint (D19); and the default-branch name comes from the project list the drawer already loads (D20), which also finally gives a root node's Start-session dialog a named base. Validation after green found four defects, two of them design errors: an **empty** default branch made the entire recovery a silent no-op (empty target selected the drop-merged-parents rule, which drops nothing in this very case — daemon now substitutes its resolved default), Repoint had no re-entrancy guard against a double rebase+force-push, the retain decision raced `update_stack_atomic`'s re-read, and `resolveRepointTarget`'s "unarrived resolution is unknown" rule was entirely unpinned (mutation-checked). 47 tests; `test:unit` (477) wired into the `test` scripts, having previously been invoked by nothing. Not yet verified against a live stack. Feature [pr-stack-live-status.md](../../ft/coder/pr-stack-live-status.md#repointing-a-dead-end-planned-pr-added-2026-07-26).
