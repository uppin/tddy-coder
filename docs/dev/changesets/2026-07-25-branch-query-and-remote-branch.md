# 2026-07-25 — **branch-query-and-remote-branch

**Type:** Feature

a `QueryBranch` RPC that resolves session/worktree/PR for a head branch, a pre-checked "Create Remote Branch" toggle that pushes the new branch at session start, and a concrete "New branch from base: `<name>`" label** — all additive over pr-stack-live-status. **tddy-service**: `proto/connection.proto` adds the unary `QueryBranch` RPC + `BranchResolution`/`BranchSession`/`BranchWorktree` (reusing `PrStatusView`) and `StartSessionRequest.create_remote_branch = 28` (regen Rust + `connection_pb.ts`). **tddy-core**: `worktree::push_new_branch_to_origin` (`git push -u origin <branch>` via `git_remote_command`) + public `worktree_path_for_branch`. **tddy-daemon**: `query_branch` handler (reuses the `get_pr_status` prologue + `get_pr_by_head` + branch→session scan + `worktree_path_for_branch`); `create_remote_branch` threaded through the three session-start intent helpers → push after worktree creation → `Changeset.remote_pushed = true` (push failure fails `StartSession`, no fallback). **tddy-web**: `useQueryBranch` (per-branch poll → `Record<string, BranchResolution>`) driving worktree/in-progress/PR row fields (`pr-stack-worktree-<nodeId>`, `pr-stack-session-<nodeId>`); `CreateSessionPane` pre-checked "Create Remote Branch" checkbox + "New branch from base: `<label>`" caption + `CreateSessionInitialValues.{createRemoteBranch,baseBranchLabel}`; new pure `utils/deriveStackBaseBranch.ts`.
