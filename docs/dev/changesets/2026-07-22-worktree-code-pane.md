# 2026-07-22 — **worktree-code-pane

**Type:** Feature

split-screen worktree file browser for every session type** — a **Code** toggle in the web `SessionMainPane` opens a `react-resizable-panels` split beside any base view (terminal / workflow chat / PR-Stack), showing a lazy directory tree of the session's git worktree and a read-only file preview. Backed by two new session-token-validated `ConnectionService` RPCs — `ListWorktreeDirectory` (one directory level; `.git`/`.gitignore`-excluded; dirs-first) and `ReadWorktreeFile` (size-capped UTF-8) — rooted at `SessionEntry.repo_path` and gated on the shared `worktrees::worktree_path_is_listed` (worktree must appear in the project's `git worktree list`). Daemon filesystem/git policy lives in `worktree_files` (traversal rejection + canonicalize-and-contain; a linked worktree's private `info/exclude` fed via `--exclude-from`). Web adds `WorktreeCodePane`/`WorktreeFileTree`/`worktreeFilesApi` and a shared `renderSimpleMarkdown` extracted from `SessionFilesPanel`; the base view stays in a stable always-mounted `Panel` so toggling never re-mounts a live terminal/chat. Tests: Rust `worktree_files` 8 + `worktree_files_rpc` 6; Cypress `WorktreeCodePaneAcceptance` 7. Feature [session-code-pane.md](../../ft/web/session-code-pane.md).
