# 2026-10-23 — Project-home git tools gated on target activity (#project-home 7/7)

**PR:** #702 · **Packages:** tddy-worktree-service, tddy-tool-engine, tddy-daemon-rpc

A project-home session commits and pushes another session's worktree in its project at any time; rebase, stash, reset, checkout, clean and force-with-lease push run only while that session is inactive and are refused naming it otherwise. A conflicting rebase is aborted and its paths reported. Feature: [project concept § Git tools](../../ft/daemon/project-concept.md#git-tools). Package entries: [tddy-worktree-service](../../../packages/tddy-worktree-service/docs/changesets/2026-10-23-session-git-ops.md), [tddy-tool-engine](../../../packages/tddy-tool-engine/docs/changesets/2026-10-23-project-home-git-tools.md), [tddy-daemon-rpc](../../../packages/tddy-daemon-rpc/docs/changesets/2026-10-23-project-home-git-tools.md).

Decisions: rebase is gated (developer, 2026-10-22) — it rewrites files under a running agent; force-with-lease push is gated — it rewrites the remote branch the agent builds on; commit is allowed while active. A rebase conflict is a result (`is_error` false, `{conflict_paths, aborted: true}`), not an error. Commands run with the target's `GIT_*` identity, the one `SessionAccountAccess::session_identity_in` resolves at session start; when it does not resolve, the checkout's inherited identity applies — confirmed at wrap that no fallback identity is added (the env is simply empty). The seven defs are built by `project_home_git_tool_defs()`; advertising them in the project-home `ListExecTools` is left to node 5's per-session advertisement (`docs/dev/todo/2026-10-23-project-home-read-only-catalog-not-advertised.md`).

Test fixture: the acceptance fixture sets `user.name`/`user.email` on the source repository. Confirmed correct at wrap — the fixture's projects carry no account and `local_gh: false`, so the daemon's git commands get an empty identity env and fall to repository config; session worktrees share the source repository's config, and a CI runner has no global identity for the commits and rebase replays the tests make.
