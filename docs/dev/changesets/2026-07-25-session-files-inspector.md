# 2026-07-25 — **session-files-inspector

**Type:** Feature

Files tab: uploaded files listed in the Inspector and reusable in the terminal** — the web Session Inspector gains a **Files** tab that lists the files already uploaded to a session (`{session_dir}/uploads/{upload_id}/{file_name}`) as a flat, newest-first list, so an upload stays repeatedly usable instead of its host path being typed once at drop time. Reuse a file by **dragging** its row onto the terminal (desktop; the drag carries the host path under the private MIME `application/x-tddy-host-path` and `TerminalFileDropZone` inserts the shell-quoted path **without re-uploading**) or **tapping/Insert** (mobile; routed to the focused terminal via a new `SessionRuntimeRegistry.setInsertInput` hook); either route **auto-closes the Inspector** so the terminal beneath becomes the drop target. Rows also Copy path (insecure-origin-safe `lib/clipboard.ts`) and two-step Delete. **tddy-service**: `proto/connection.proto` adds `ListSessionUploads`/`DeleteSessionUpload` RPCs + `SessionUploadEntry` (regen Rust + `connection_pb.ts`). **tddy-daemon**: new `session_uploads` module (`list_uploads` flat newest-first walk, missing root → empty; `delete_upload` reuses the writer's basename + canonicalize-and-contain guard, `NotFound` for a missing file, prunes the emptied `upload_id` folder), the extracted shared `session_file_upload::{validate_segment, contained_canonical_dir}` guard, two `ConnectionServiceImpl` handlers, and tonic-adapter forwarding. **tddy-web**: `SessionFilesTab`, `InspectorTabs` "files" tab, `TerminalFileDropZone` internal-drag branch, `lib/clipboard.ts` + `lib/hostPathDrag.ts`, and the focused-terminal insert route threaded `SessionsDrawerScreen → SessionMainPane → SessionInspectorDrawer` plus `SessionRuntime`/terminals registering `insertInput`. Tests: tddy-daemon `session_uploads_rpc` 13 (+ `session_file_upload_rpc` 9 regression), Cypress `SessionFilesTabAcceptance` 6 / `SessionInspectorFilesTab` 2 / `TerminalDropInsertHostPath` 2; `cargo fmt --check` + `clippy -p tddy-daemon --tests -D warnings` clean.
