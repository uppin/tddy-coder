# 2026-07-25 — **enqueued-input-overlay

**Type:** Feature

accountable terminal input on slow links: each `SendTerminalInput` carries a cumulative byte `input_offset` and the server acks the applied offset on `StreamTerminalOutput`, driving a single-line overlay of un-acknowledged input** — **tddy-service**: `proto/connection.proto` adds `SessionTerminalInput.input_offset = 6` and `SessionTerminalOutput.acked_input_offset = 2` (regenerated Rust + `connection_pb.ts`). **tddy-task**: `AppliedOffset` (monotonic `AtomicU64` accumulator) + `TaskChannel` gains the applied-offset/ack `watch` state (`acknowledge_input`/`subscribe_acked_offset`) — the shared home so a `PtyHandle` rebuilt per RPC still shares ack state. **tddy-daemon**: `PtyHandle::send_input(data, input_offset)` acks via the channel; `send_terminal_input` threads the offset; `stream_terminal_output` interleaves ACK frames (`SessionTerminalOutput{data:[], acked_input_offset}`). **tddy-coder**: session participant + `terminal_manager` do the same for bash tabs. **tddy-web**: `terminalInputQueue` (classify keyboard/mouse/control, offset accounting, ack-trim, overlay model), `useEnqueuedInput` (500 ms reveal timer), `EnqueuedInputOverlay`, wired into `GrpcSessionTerminal`.
