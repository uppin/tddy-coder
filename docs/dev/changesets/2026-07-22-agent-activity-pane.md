# 2026-07-22 — **agent-activity-pane

**Type:** Feature

per-session agent tool-call log, live stream, and overlay UI** — a new per-session **`agent-activity.jsonl`** log (sibling of `tool-calls.jsonl`) captures the **agent's own** tool loop, distinct from the human-triggered `ExecuteTool` web-invoke log. The shared **`AgentActivityRecord`** + append/coalesce-by-`call_id`/500-cap read live in **`tddy-core::agent_activity`** (one cross-crate shape); `ProgressEvent` gains `input_json`/`call_id` on `ToolUse` plus a new additive `ToolResult` variant. **`tddy-service`** adds `AgentActivityRecord`, server-streaming `StreamSessionActivity` (snapshot-then-live) and unary `ReportAgentActivity` (regen Rust + `connection_pb.ts`). Capture has **one seam per session type**: the **daemon** `DaemonToolHandler::execute` (sandbox), the `tddy-tools session-hook` Pre/Post → `ReportAgentActivity` (claude-cli), and the **coder** presenter broadcast (tool/cursor-cli). The daemon hosts an `AgentActivityHub` + the stream/report handlers (**Local-only**; peer-forward returns `unimplemented`, a follow-up), and the coder participant serves `StreamSessionActivity` over LiveKit while live. Web `useSessionActivity` + `AgentActivityOverlay` (icon, unread badge, overlay list, full input/output detail dialog) wire into `SessionMainPane`. Tests: `tddy-core` agent_activity 5 + stream + presenter, `tddy-tools` session_hook 4, `tddy-daemon` sandbox_session + connection_service 5, `tddy-coder` participant, web Cypress `AgentActivityAcceptance` 8.
