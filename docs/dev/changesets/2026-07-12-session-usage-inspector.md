# 2026-07-12 — **session-usage-inspector

**Type:** Feature

real-time per-session token usage in the web Inspector** — a new **Usage** tab in the Session Inspector shows a live per-conversation token breakdown (main agent + subagents: input/output/total tokens, turns) with a summing TOTAL row. Rides the existing generic `ServerMessage` oneof on `TddyRemote.Stream` via a new `TokenUsageUpdated` variant carrying the full cumulative `ConversationRecord` snapshot (never a delta) — no new endpoint. `tddy-core`: `PresenterEvent::TokenUsageUpdated`; `backend::gather_session_usage()` (main transcript + Claude Task subagents + `egress/accounting.json`, extracted from `tddy-sandbox-app`'s `print_token_summary`); `usage_watcher` module — `SessionUsageEmitter` (broadcast+dedup), poll-based `spawn_usage_watcher`, session-level `spawn_session_usage_watcher` (derives `include_main_agent` from the agent), moved from `tddy-daemon`. `tddy-service`: proto `TokenUsageUpdated`/`ConversationRecord` on the `ServerMessage` oneof + `event_to_server_message` mapping. `tddy-coder`: `run_daemon` spawns the watcher on the session's presenter `event_tx` (aborted on shutdown) so a running session broadcasts live usage → web. `tddy-web`: `formatTokens`, `sessionUsage`, `useSessionUsage` (owned by the tab), `SessionUsageTab`, `"usage"` tab wired into the inspector. **Follow-ups (out of scope):** snapshot-on-connect replay for a mid-session View (`connect_view` snapshot omits usage — a late subscriber sees usage only on the next poll tick); end-to-end production rendering still needs the presenter stream's LiveKit `Room` threaded through (`usePresenterChat.ts:98`).
