# 2026-07-24 — **activities-as-acp

**Type:** Feature

session activity overlay becomes a read-only ACP transcript** — the web `AgentActivityOverlay`'s flat tool-call row list + JSON detail dialog is replaced by a **read-only, ACP-style conversation transcript** (agent text interleaved with tool calls enriched to `Read main.rs L10-49`, a running/error status chip, and a DEBUG `+Ns` elapsed badge from real event timestamps), rendering for **both live and dormant** sessions. The session persists its own ACP-mapped conversation to **`acp-transcript.jsonl`** (self-contained — no dependence on the agent-CLI-owned `conversation.jsonl`), written at event time by **tddy-coder**'s `spawn_acp_transcript_writer` (consumes `presenter_events`; `AgentOutput`→agent-text frame, `AgentActivity`→enriched tool frame via `tddy_service::acp_replay::frame_for_agent_activity`). A new server-streaming **`StreamAcpReplay`** RPC (on `ConnectionService`, returning `AcpReplayFrame { bytes acp_agent_message }` — the ACP `AcpAgentMessage` as bytes, keeping `connection.proto` self-contained) replays the persisted snapshot then tails live, served by the **tddy-coder** participant (LiveKit) and the **tddy-daemon** (`/rpc` snapshot + `AgentActivityHub`) + tonic adapter, mirroring `StreamSessionActivity` (Local-only; `PeerRoute::Forward` → `unimplemented`). **tddy-service** adds `acp_replay.rs` (frame builders + `serialize/deserialize` + `read_acp_transcript`) and `timestamp_unix_ms` on ACP `SessionNotification`; **tddy-core** enriches `tool_use_detail` with `Lstart-end` line ranges. **tddy-web** adds `useAcpReplay` + `acpAgentMerge` and a `readOnly` `AgentChatView` (tool cards + timing badge, coalescing tool frames by `tool_call_id`); the overlay body becomes `<AgentChatView readOnly>`. `StreamSessionActivity` retained (unused by the overlay), reserved for future system session messages; persisting agent *text* for hook-driven claude-cli/sandbox is a follow-up. Also fixed a pre-existing broken test target (`session_catalog_populate.rs` → `tddy_bsp::register_catalog_provider()`). Tests: tddy-service acp_replay 5, tddy-core stream::claude 3, tddy-coder acp_transcript 2 + participant `stream_acp_replay`, tddy-daemon `stream_acp_replay` 2, Cypress `AgentActivityAcpReplayAcceptance` 8; `cargo clippy --workspace --all-targets -D warnings` clean.
