# 2026-07-21 — **host-stats-footer

**Type:** Feature

persistent bottom footer with disk + per-core CPU; byte-traffic relocated** — a screen-level Host Stats Footer on the sessions drawer moves the byte-traffic readout out of the top header and adds two host-level indicators for the selected daemon: available disk space (60 s poll) and per-core CPU mini bars (5 s poll). Two new session-token-validated `ConnectionService` unary RPCs (`GetHostCpuStats`/`GetHostDiskStats`) are served by a `sysinfo`-backed `HostStats` provider in `tddy-daemon` (`host_stats.rs`: long-lived per-core CPU sampler; `select_mount_for_path` longest-path-component-prefix disk resolution against `$HOME/<repos_base_path_or_default>` with a largest-mount fallback), wired into `ConnectionServiceImpl` (default `SysinfoHostStats`, `with_host_stats` test seam; tonic adapter delegates). Web adds `HostStatsFooter`/`DiskSpaceIndicator`/`CpuCoresIndicator` + `useHostCpuStats`(5 s)/`useHostDiskStats`(60 s) hooks + `hostStatsFormat` (`formatDiskFree`/`clampCorePercent`); `SessionTrafficStrip` moves from the header into the footer. Drive-by: a `#302` test-helper `type_complexity` clippy fix (`SpawnConversationArgs` alias). Tests: `host_stats` units (4) + handler token/mapping units (4); Cypress `HostStatsFooterAcceptance` (4) + `SessionTrafficBarFooter` (5, replacing the retired top-toolbar spec); `hostStatsFormat.test.ts` (6); full web component suite green apart from the pre-existing `#297` `SessionStartResumeStillDaemonRouted` timing flake.
