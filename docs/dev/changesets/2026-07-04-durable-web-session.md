# 2026-07-04 — **durable-web-session

**Type:** Feature

refresh-token + RPC token gate** — fixes web users being logged out whenever their device slept or a tab was backgrounded past the 5-minute access-token TTL. `tddy-github::session_token` gains a `TokenKind` (`access`/`refresh`) claim (serde-default `access` for legacy tokens already in browsers) plus `mint_access`/`mint_refresh`/`REFRESH_TOKEN_TTL` (7 days); `ExchangeCode` now mints both an access token and a refresh token, and `RefreshSession` (`auth.proto`, `refresh_token` field replacing the old `session_token` refresh input) consumes a refresh token — rejecting an access-kind one — and returns a new access token plus a slid (fresh 7-day) refresh token. `tddy-daemon`'s per-RPC session resolver symmetrically rejects a refresh-kind token, so neither credential can do the other's job and the refresh token is the sole source of new access tokens once logged in. `tddy-web`: new single-flight `sessionTokenStore` (decodes the access token's `exp` client-side, dual-token `localStorage`) and `authGateInterceptor` (ConnectRPC interceptor on the HTTP transport that awaits a fresh token and rewrites each request's `sessionToken` field at send-time — no call-site changes across ~30 existing usages) replace sole reliance on a 4-minute `setInterval`; `AuthProvider` drives a transparent refresh on mount when the stored access token is expired but the refresh token is valid, exposes `isRefreshing`, and a top-bar indicator shows while a refresh is in flight. Daemon-level LiveKit RPCs stay fresh via the shared context token (LiveKit's custom `Transport` has no interceptor seam; gating it directly is a follow-up). `cargo test -p tddy-github -p tddy-daemon` + clippy clean; TS units 8/8; Cypress `DurableSessionAcceptance` 5/5 + rewritten `AuthProviderRefreshAcceptance` 4/4; full component suite 420/423 (3 pre-existing `PlannedPrRowInternalStatusAcceptance` failures, confirmed identical on master, unrelated); whole-workspace `cargo build`/`./test` green (414 suites, 0 failures).
