# 2026-07-27 — **cursor-cli-skip-keychain

**Type:** Fix

sandboxed Cursor Agent CLI no longer hangs on macOS Keychain** — a sandboxed `agent` on macOS hung ~30s on `securityd` and failed with `Failed to store authentication tokens: Security command failed: Security process exited with code: 36` / `errSecMissingEntitlement` (-34018), because the host (`tddy-daemon` / `tddy-sandbox-app`) is an unsigned Rust binary with no `keychain-access-group` entitlement and the Cursor CLI still probes Keychain for `cursor-user` even when `CURSOR_API_KEY` is set. Two fixes: `tddy-sandbox-recipes::cursor_runner_env_overlay` now emits `CURSOR_SKIP_KEYCHAIN=1` + `CI=true` (Cursor's own CI convention) alongside `CURSOR_TMPDIR`; and `tddy-daemon::sandbox_session::build_sandboxed_cursor_runner_env` (new pure helper, no `&self` deps — unit-testable without a Seatbelt/cgroups harness) is now called by `start_sandboxed_cursor_cli_session` instead of inline env assembly (the overlay was previously defined but never called from the cursor spawn path — only the Claude overlay was wired, unconditionally, via `build_sandbox_runner_env`). The caller still has to supply `CURSOR_API_KEY` (User API key — admin keys are rejected) or pre-seed `~/.cursor/auth.json` via `seed_cursor_credentials`; this removes a path that cannot work in a sandbox, it does not authenticate. The bogus `AGENT_CLI_CREDENTIAL_STORE=file` reference in [cursor-cli-session.md § Known follow-ups](../../ft/daemon/cursor-cli-session.md#known-follow-ups) is corrected to the real recipe. Per-package: [tddy-sandbox-recipes](../../../packages/tddy-sandbox-recipes/docs/changesets/), [tddy-daemon](../../../packages/tddy-daemon/docs/changesets/). Tests: 2 recipe-layer (`cursor_runner_env_overlay_*`) + 1 daemon-layer (`cursor_runner_env_skips_keychain_so_the_jailed_agent_never_probes_securityd`); `cargo build -p tddy-daemon`, `cargo clippy -p tddy-sandbox-recipes -p tddy-daemon -- -D warnings`, `rustfmt --check` all clean. Follow-ups: `build_sandbox_runner_env`'s unconditional `claude_runner_env_overlay` leak into cursor sessions; codesigning `tddy-sandbox-app` for true Keychain *access* (not pursued — fail-closed with `CURSOR_API_KEY`); end-to-end daemon integration test for `start_sandboxed_cursor_cli_session`. (tddy-sandbox-recipes, tddy-daemon)
