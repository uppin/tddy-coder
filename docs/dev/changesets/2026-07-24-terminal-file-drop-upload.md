# 2026-07-24 — **terminal-file-drop-upload

**Type:** Feature

drag a file onto the web terminal to upload it to the host session dir and type its path** — dragging files onto the Ghostty web terminal (gRPC or LiveKit) uploads them in client-driven ordered chunks to `{session_dir}/uploads/<upload_id>/<file_name>` on the host and types the uploaded files' shell-escaped absolute host paths into the terminal input (space-separated, trailing space, no newline), emulating a native terminal file-drag; aggregate progress shows in the Host Stats Footer and auto-hides, a failed file is skipped and surfaced, and mobile initiates the gesture from an Attach button in the Keyboard strip. **tddy-service**: new unary `UploadSessionFileChunk(UploadSessionFileChunkRequest{session_token,session_id,upload_id,file_name,data,last}) returns (UploadSessionFileChunkResponse{host_path})` on `ConnectionService` (regenerated Rust + `connection_pb.ts`). **tddy-daemon**: new `session_file_upload` module (`write_upload_chunk` basename-validates `upload_id` and `file_name`, appends chunks, and applies a canonicalize-and-contain guard rooted at the trusted `{session_dir}/uploads` root; returns the absolute host path on the final chunk) + an `upload_session_file_chunk` handler that authenticates the session token before any filesystem access. **tddy-web**: `TerminalFileDropZone` + mobile `TerminalUploadButton`, `useSessionFileUpload` chunked orchestration, a shared `UploadProgressStore`/provider + `UploadProgressIndicator` in the footer, and `shellQuote`/`fileUploadChunks` helpers; both terminal transports thread the insert path. Tests: tddy-daemon `session_file_upload_rpc` 9 (chunk append/host-path, per-`upload_id` isolation, basename/traversal rejection for `file_name` and `upload_id`, unauthenticated-token), tddy-web `shellQuote`/`fileUploadChunks`/`uploadProgress` units 18, Cypress `TerminalFileDropUpload`/`TerminalFileUploadProgressFooter`/`MobileTerminalUploadButton`/`TerminalFileUploadFailure` 10; clippy `-D warnings` clean.
